## 四、后续步骤规划（Stage S 展开）

> PLAN.md §5 已登记 S1〜S4。本节给出各步骤的输入/输出/验收，供下一阶段执行。

### S1 播音稿件转换
- 输入: `production/draft-A/B/C/D.md`（本报告 §三 的两项前置确认完成后）
- 作业: 书面语 → 口语化；按 30-40 分总长估算分段时长（日语播报约 300 字/分钟基准）；
  标注语气/停顿/强调；数字读法统一（如「53,178.41」→「五万三千百七十八ポイント」）
- 输出: `production/broadcast-script.md`（分幕+推定秒数）
- 验收: 全文朗读时长落在 33-42 分；铁则一/二保留；免责在开头结尾

### S2 视觉模板设计与画面输出
- 输入: `spec/vision-design.md` §1〜§7（已有 1对1 规格）+ S1 的分幕结构
- 作业: 把 §0 设计系统（色板/字体/网格/动画语汇）落地为可复用组件
  （建议 React/Remotion 组件，与 S3 共用）；按当日内容为每个分幕产出画面数据
  （标题/要点/出处/配色风格切换点）
- 输出: 模板组件库 + `production/scenes.json`（每幕的画面数据与持续时长）
- 验收: 两种风格（明亮新闻风/黑板深度风）可切换；无图表规则（§0.6）遵守；
  字幕区与署名区预留

### S3 Remotion 脚本（音画同步）
- 输入: S1 播音稿（含分段时长）+ S2 场景数据 + TTS 语音（或占位音轨）
- 作业: Remotion Composition 编排：以音轨时长为时间轴主干，
  场景切换对齐分幕边界，字幕逐句同步，动画节奏按 §0.7（淡入/滑入/高亮）
- 输出: `remotion/` 工程（Composition、时间轴映射表）
- 验收: 预览播放无空白帧/错位；1920×1080；幕间风格切换点与稿件一致

### S4 合成试产（延伸）
- TTS 生成日语语音 → Remotion 渲染样片 → 端到端抽查音画同步与字幕。

### 执行顺序建议
1. 先补两项前置确认（B-3/C-5）→ 2. S1 → 3. S2 与 S3 的组件骨架可并行设计，
   但画面数据依赖 S1 分幕 → 4. S3 → 5. S4 样片。
