# ブランドアセットキャッシュ一覧

> 企業・メディアロゴの全日共有キャッシュ。PLAN.md 3.10 節参照。
> **原則**: 必要になった時、まずここを確認 → あれば再利用（再取得しない）／ なければ検索DL → 保存 → **下表に必ず1行追記**する。

## 取得フロー

```
1. assets/brands/{companies,media}/<slug>.png を確認
   - あり → 再利用（キャッシュ命中）
   - なし → 手順2へ
2. 検索・ダウンロード（優先: 公式IR／プレスキット／ブランドアセット → Wikipedia → ロゴ検索）
3. 所定パスへ保存（背景透過 PNG／SVG 推奨）
4. 下表に1行追記（slug / 種別 / 取得元URL / 取得日 / 形式 / 使用条件）
5. 保存したファイルを使用
```

## 命名規約

- 企業: ticker 小文字（`nvda.png`）。メディア: ケバムケース（`goldman-sachs.png`）。
- 形式は PNG 標準。SVG 併存可（同名で）。
