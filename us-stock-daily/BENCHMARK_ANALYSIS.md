## 二、テーマ選定方法論

**テーマ選定の情報源優先度:**
1. 公式文書/データ (FRB議事録、SEC提出書類) — 最高の権威性
2. トップクラスの投資銀行リサーチレポート (Goldman Sachs、UBS、Morgan Stanley) — 専門分析による裏付け
3. 専門分析機関 (SemiAnalysis、Glassnote) — 垂直領域の深掘り
4. 主要経済メディア (Bloomberg、WSJ) — 時宜性と網羅性
5. オンチェーン/オルタナティブデータ (Glassnote、ETF資金流入) — 差別化された視点

**テーマ選定4象限基準 (2つ以上を満たすこと):**
- 🔥 当日の最大ホットトピック (市場の注目度)
- 🧠 深掘り分析の余地がある (単なるニュース速報ではない)
- ⚔️ 議論/見解の分裂がある (タカ派vsハト派、強気vs弱気)
- 💰 実行可能な投資含意がある (ポジション提案、ペアトレード)

**内容の深掘り度階層:**
| レベル | 時間 | 適用シーン | 情報密度 |
|--------|------|-----------|----------|
| 核心的深掘り | 7分+ | AI商用化、ビジネスモデル変革 | 10+データポイント |
| 中程度分析 | 4分 | マクロ政策、セクター動向 | 5-8データポイント |
| クイックスキャン | 3分 | 単一資産の値動き | 3-5データポイント |
| ニュース速報 | 20秒/本 | 速報まとめ | 1-2データポイント |

## 三、内容展開方法論

**各深掘りテーマの展開フォーマット:**

```
① データ/イベントで開始 (事実を提示)
② 核心的な問いを立てる (サスペンスを作る)
③ 権威ある情報源を引用 (2-3のクロスチェック)
④ ホストの独自解釈 (個人判断)
⑤ 投資含意/アクション提案 (実践に落とす)
⑥ リスク注意喚起 (コンプライアンス+誠実さ)
```

**データドリブンな語りのルール:**
- 各論点には具体的な数字の裏付けが必須 (パーセンテージ、金額、倍率)
- データには比較の次元を持たせる (過去vs現在、A社vs B社)
- パーセンテージデータの密度: 平均27秒に1回パーセンテージが出現 (23分間で51回)

**複数情報源のクロスチェックルール:**
- 同一テーマについて少なくとも2つの異なる権威ある情報源を引用
- 正反対の見解を並べて提示 (タカ派vsハト派、強気vs弱気)
- 情報源を明確に表示し、曖昧な帰属をしない

**ホストの4つの役割:**
1. **情報統合者** — 複数の情報源の核心的見解を集約し、視聴者の時間を節約
2. **独立思考者** — 個人判断を表現し、曖昧さを排除
3. **実践指導者** — 実行可能な投資助言と具体的戦略を提示
4. **リスク守護者** — すべての提案にリスク注意喚起と過去の反例を付随

**見出しのフォーマット:** `[議論/サスペンス?] + [選択対比?] + [衝撃データ!] + [アクションシグナル!]`

## 五、言語スタイル規範

- **口語体だが専門性は保つ**: 文語調を避け、友人と話すように専門内容を語る
- **適度なユーモアと感情**: "彼らが明日もっと酷い目に遭えばいいのに" — 本音を隠さない
- **見解を直接的に表現**: "かもしれない・たぶん・おそらく"とは言わず、"結局はインフレ次第"と言う
- **適度な自虐**: "もちろん、当てずっぽうですが" — 防衛心理を下げる
- **専門用語はその場で解説**: 専門用語が出たらすぐに平易な言葉で説明
- **相互作用の言葉は控えめ**: 全編で「皆さん」はわずか6回、視聴者に媚びない

### 7.3 画面レイアウトルール

**モジュラー・グリッドレイアウト (上から下へ階層化)**：
```
┌───────────────────────────────────────┐
│  チャンネル標識(BLACKBOARD·ブラックボード見解)  メインタイトル  │  ← 上部: ブランド+タイトル(最大フォントサイズ)
├──────────────┬────────────────────────┤
│              │  情報源標注(緑色小文字)      │
│  配図/ブランド図  │  メイン論点(赤/黄色大文字)    │
│  または Logo  │  核心データリスト           │
│  または概念図  │  (赤色=キー数字)        │
│              │  (黒色=説明テキスト)      │
├──────────────┴────────────────────────┤
│  署名(右下)   │ 埋め込み字幕(下部白色)    │  ← 下部: 字幕+署名
└───────────────────────────────────────┘
```

**2つの構図パターン**：
- **全画面カード式** (市場速覧): 3層の並列モジュール — 指数データ→セクター騰落対比→その他市場+ポイント要約
- **左図右文式** (深掘り分析): 左40%にブランド図/概念図、右60%にテキスト論述

### 7.4 テキスト表現のテクニック

| テクニック | 具体的な做法 | 効果 |
|-----------|-----------|------|
| **中国語・英語バイリンガル** | "標普 · S&P 500" 形式 | 中国語視聴者に配慮+専門用語を保持 |
| **色コーディング数字** | キー数値は赤色太字、説明は黒色 | 視覚焦点を核心データに固定 |
| **記号補助** | ▲ 騰値上位 / ▼ 下落上位 | 騰落方向を直感的に表示 |
| **情報源標注** | 左上の緑色小文字 "メディア見解 · SemiAnalysis" | 情報源の裏付けを示しつつ目立ちすぎない |
| **字幕同期** | 下部の白色字幕をナレーションと同期 | 聴覚補助+ミュート視聴が可能 |
| **署名メカニズム** | 右下「—— Jason/Steven の見解」 | 客観データと個人見解を区別 |

### 7.5 色セマンティックシステム

| 色 | 用途 | 使用シーン |
|------|------|-----------|
| ダークグリーン | 背景のベースカラー | BLACKBOARD専門枠(黒板を模倣) |
| 明るい黄色 | 見出し+強調 | メイン論点、重点テキスト(蛍光ペン効果) |
| 赤色 | キー数字+警告 | 核心的バリュエーションデータ、下落数字、リスクシグナル |
| 緑色 | 情報源標注+上昇 | 情報の出所、市場上昇数字 |
| 白色 | 本文+字幕 | 本文リスト、下部字幕 |
| オフホワイト/クリーム | 背景 | 明るいニュース風スタイル(柔らかな紙のレポート感) |
| ライトグリーン/ライトピンク | 色ブロック分類 | 騰値上位セクター(緑背景) vs 下落上位セクター(ピンク背景) |

### 7.6 データ表示方式

当チャンネルは**伝統的なチャートを使用しない**（ローソク足、折れ線、棒グラフなし）、代わりに：

1. **純数字 + 色コーディング**: 例 S&P -0.28% (赤色), NASDAQ +0.20% (緑色)
2. **色ブロック分類**: ライトグリーンのブロック=騰値上位セクターリスト, ライトピンクのブロック=下落上位セクターリスト
3. **論理的階段リスト**: データを論理的に段階的に展開 (現状→成長率→予測→バリュエーション導出)
4. **象徴的配図**: ブランドLogo/概念図でデータチャートを代替(例: ビットコイン+警告テープ=リスクの暗喩)
5. **テキスト化データ**: "過去に何度も80%超の下落" — 生データを示すのではなく結論を直接陳述

### 7.7 画面切り替えのテンポ

| コーナー | テンポの特徴 | 画面持続時間 |
|---------|-----------|------------|
| 市場速覧(sec2) | 単一カードを持続的に表示、情報が高密度 | 60-90秒/画面 |
| リサーチレポート解読(sec4) | 画面切り替え/アニメーション遷移あり | 15-30秒/画面 |
| 半導体分析(sec5) | 単一の情報図を持続 | 30-60秒/画面 |
| 結論/注意喚起(sec6) | スタイル切り替え(暗→明+赤色)を転換のアンカーに | 10-20秒/画面 |

### 7.8 画面表現方法論のまとめ

1. **PPTスライドスタイル**: 純図文+ナレーション、出演コストゼロ、画面は完全に情報伝達に奉仕
2. **コンテンツタイプ別のスタイル切り替え**: 速報は明るいカード風(敷居を下げる)、深掘り分析はブラックボード風(専門感を醸成)
3. **左図右文の標準構図**: 左側にブランド図/概念図をビジュアルアンカーとして配置、右側にテキスト論述
4. **色コーディングの一貫性**: 赤=キー/警告, 黄=強調/重点, 緑=情報源/上昇、視聴者に条件反射を形成
5. **署名で立場を区別**: 客観データには署名なし、個人見解には「—— Jasonの見解」と標注
6. **伝統的チャート不使用**: 純数字+色コーディング+リスト、チャートより直感的で小画面視聴に適する
7. **字幕+署名は固定位置**: 下部字幕エリア+右下署名エリア、位置は常に不変
