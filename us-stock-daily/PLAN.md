# 米国株式デイリー深層分析 — 番組制作計画書

> バージョン: v3.0 | 更新日: 2026-07-14
> 番組定位: 毎日30-40分 | 個人投資家向け | 長期投資＋実践的アクション指針
> **出力言語: 日本語** | **ターゲット: 日本の個人投資家**
> ベンチマーク: [美投侃新聞チャンネルの方法論](./BENCHMARK_ANALYSIS.md)

---

## 一、コア制作原則

### 1.1 番組定位

毎日30-40分の米国株深層分析番組。日本の個人投資家向け。単なるニュース読み上げではなく：
- **専門情報提供者**: 複数の権威ある情報源を集約し、専門的で深い解説を提供する
- **実践的アクション指導者**: 実行可能な価格水準とポジションサイズの目安を示す
- **長期投資の提唱者にして個人の守り手**: リスナーの分散投資・適正ポジション管理・リスク管理への意識を高め、長期投資の理念で「個人がウォール街に勝つ」ことを目指す

### 1.2 二つの鉄則

#### 鉄則一：オープニングの核心予告＋サスペンス作り

30-40分の長尺番組では、冒頭は単なる速報で終わらせてはいけない。必ず：

1. **市場速報** (1-2分): 具体的な数字で市場全体を素早くスキャン
2. **本日の核心予告** (1-2分): 本日の3-5個の核心的見どころをリストアップ。各見どころについて核心となる問いを一言で要約し、リスナーに「この番組を聴き終えればその答えが得られる」と思わせる


#### 鉄則二：個別株／セクター分析には必ず大手アナリスト目標株価＋具体的なアクション価格を示す

個別株またはセクター指数の分析に触れる際、**必ず**以下を含める：

1. **大手目標株価**: 少なくとも1社の著名投資銀行の目標株価とレーティングを引用
2. **具体的アクション指針**: 明確な買い建て／積み増し／縮小／損切りの価格水準を提示
3. **ポジション目安**: ポジション比率または分割買い戦略を提示

**アクション指針の出力フォーマット:**
```
「[銘柄／セクター] については、私はこう動きます：
- [大手名] の目標株価 [XX] ドルを参考にします（現在のレーティング：買い／中立／売り）
- [XX-XX] のレンジなら、[X%] の初期ポジションを構築することを検討します
- [XX] まで押し戻されたら、[X%] まで積み増します
- 損切りは [XX]、下抜けたら認めて離場します
- 目標値は [XX]、到達で半分利確します」
```

**例:**
```
「エヌビディア（NVDA）については、私はこう動きます：
- バンク・オブ・アメリカの目標株価 190 ドルを参考にします（現在のレーティング：買い）。モルガン・スタンレーも 185 ドルを出しています
- 現在 155 ドル。150-160 のレンジで 30% の初期ポジションを構築します
- 市場パニックで 135 まで押し戻されたら、60% まで積み増します
- 損切りは 120、20% 移動平均を下抜けたら認めます
- 第1目標値 180、到達で半分利確、残りは 200 を睨んでホールドします」
```

### 1.3 データ密度の基準

ベンチマークの高密度スタイルを踏襲：
- **30秒に最低1個の具体的データポイント** (パーセンテージ／金額／倍率)
- すべての核心的論点に数字の裏付けを持たせ、空論を排する
- データには必ず比較の次元を持たせる (過去 vs 現在、A社 vs B社、予想 vs 実績)

### 1.4 複数情報源の交差検証

- 同一トピックについて最低 **2つの異なる権威ある情報源** を引用
- 正反対の見解を並列提示 (タカ派 vs ハト派、強気 vs 弱気)
- 情報源を明確に表示し、曖昧な帰属を避ける
- 情報源の優先順位: 公式文書 > 投資銀行リサーチ > 専門機関 > 主要メディア

### 1.5 言語スタイル

- **口語体だが専門性を保つ**: 友人と話すように専門内容を語る
- **見解を率直に表現**: 「〜かもしれない・たぶん・おそらく」と言わず、「結局のところインフレ次第です」と言う
- **適度な自嘲**: 「もっとも、これは私の判断にすぎません。市場は常に正しいのですけれど」
- **専門用語は即時解説**: 専門用語が出たら直ちに平易な言葉で説明する
- **媚びない**: 「みなさん」「皆さま」といった決まり文句は控えめに使う

## 二、番組全体構成

### 2.1 コーナー構成と時間配分 (30-40分)

| コーナー | 時間 | 頻度 | 核心定位 |
|----------|------|------|----------|
| **OP. オープニング俳句** | 30秒 | 毎日固定 | ブランド識別、雰囲気醸成 |
| **A. 市場速報＋核心予告** | 3-4分 | 毎日固定 | 市場スキャン＋本日の見どころ＋サスペンスのフック |
| **B. マクロ深層分析** | 5-8分 | イベント駆動 | 当日最重要のマクロテーマを掘り下げ |
| **C. 大手リサーチ精選** | 5-8分 | イベント駆動 | 市場への影響力がある機関の見解を解説 |
| **D. 個別株／セクター深層分析** | 10-15分 | 毎日固定(核心) | 業界の縦深＋バリュエーション＋**アクション指針** |
| **E. 投資戦略とリスク管理** | 3-5分 | 毎日固定 | ポジション管理、心理面の誘導、リスク警告 |
| **F. ニュース速報レビュー** | 2-3分 | 毎日固定 | 8本の精選ニュース、各30字以内 |
| **G. エンディング** | 1分 | 毎日固定 | まとめ＋次回予告 |

### 2.2 オープニング俳句 (30秒)

#### 目的
番組開始30秒以内にリスナーの注意を掴み、俳句形式で当日の核心テーマを凝縮する。

#### 俳句フォーマット
```
【例1】
AI波　半導体躍る　利下げ待ち
黄金（こがね）光り　現金の夏
時を見守る

【例2】
決算良し　科技（テック）巨頭歌う
債市の警鐘　賢い資金迷う
進退の間に　ポジションが運命を決める
```

#### 制作ルール
1. 基本5-7-5音（俳句）。1-3句で当日の核心1-3テーマを凝縮
2. 当日最も核心的な1-3テーマを凝縮
3. 視覚: 高級感ある背景（黒／金／深緑）＋白／金色の文字
4. ナレーション: 落ち着いた声色で朗読、余韻を残す
5. **内容は番組後半の分析と必ず呼応させる**

#### 制作タイミング
全コーナーの素材が完成したあと**最後に制作**する。番組全体の核心を凝縮する必要があるため。

### 2.3 動的調整ルール

**通常日**: OP＋A＋D＋E＋F＋G を固定放送。B／C は当日のイベントに応じて選択的に挿入

**決算シーズン** (1・4・7・10月下旬):
- Dコーナーを20分に拡大、注力決算を深掘り
- Cコーナーを起動、決算に対するアナリストの即時反応に焦点
- Bコーナーは圧縮またはスキップ

**FOMC政策金利週**:
- Bコーナーを10-12分に拡大
- Cコーナーは金利関連リサーチに焦点
- Dコーナーは短縮またはスキップ

**重大ブラックスワン事件**:
- Aコーナーを8分に拡大（全体スキャン）
- Bコーナーは必須
- Eコーナーを拡大（心理面の安撫に注力）
- Dコーナーは状況次第でスキップ

## 三、各コーナーの詳細制作方法論

### A. 市場速報＋核心予告 (3-4分)

#### 第一部: 市場速報 (1-2分)

**情報収集源:**
| 情報源 | URL | 用途 |
|--------|-----|------|
| Finviz | finviz.com | S&P 500ヒートマップ、騰落トップ |
| TradingView | tradingview.com | 複数資産チャート(US10Y, XAUUSD, BTCUSD, DXY) |
| CNN Fear & Greed | edition.cnn.com/markets/fear-and-greed | 市場心理指標 |
| Yahoo Finance | finance.yahoo.com | クイック相場概況 |

**固定放送資産:**
- 指数: S&P 500、Nasdaq 100、ダウ工業株価平均、Russell 2000
- 債券市場: 米国債2年・10年・30年利回り
- コモディティ: 金、WTI原油
- 暗号資産: BTC、ETH
- 為替: ドル円（USD/JPY）および DXY（ドルインデックス）— 日本の投資家にはドル円が特に重要。明確な変動がある場合に言及

**速報テンプレート:**
```
[オープン] 一言で定性 (例: 「AIセクターが引き続き主導するも、債券市場が警告シグナル」)
[指数] 主要指数の騰落%＋一言の理由
[異常値] 当日の最大上昇／下落個別株(時価総額>)＋簡潔な理由
[債券／コモディティ／暗号／為替] 重要な変動(明らかな変化のみ)
[心理] Fear & Greed指数の位置と推移
```

#### 第二部: 核心予告 (1-2分)

後続の全コーナーから核心的な見どころを3-5個抽出し、それぞれを一言で要約：

```
「本日の番組は情報量が多いので、まず要点を整理します：
1. [テーマA] — [核心の結論]
   例: 「FOMC議事録が一つの重要なシグナルを漏らした — 彼らはAIがもたらすインフレ圧力を懸念し始めた」
2. [テーマB] — [核心の結論]
   例: 「ゴールドマンがエヌビディアの目標株価を190ドルに引き上げた。しかし見落とされているリスクがもう一つある」
3. [テーマC] — [核心の結論]
   例: 「ビットコインに歴史級の買いシグナルが出た — 前回これが出たのは2020年3月だった」
…」
```

#### 第三部: サスペンスのフック (30秒)

```
「それから、番組の後半で [サスペンステーマ] を重点的に取り上げます。
この問題は現在ウォール街でも意見が大きく割れていて、[大手A] と [大手B] の見解が完全に正反対です。
私自身の判断は […] — では市場は最終的にどう動くのか？
最後までぜひご覧ください。具体的なアクション指針をお伝えします。」
```

---

### B. マクロ深層分析 (5-8分) — テーマ駆動

#### 核心理念: まず広く集め、後に精選する

**第一段階: 広範な収集** (毎日ルーチン)

| 情報源 | URL | 用途 |
|--------|-----|------|
| Investing.com 経済カレンダー | investing.com/economic-calendar | 当日／今週の経済指標発表 |
| CME FedWatch | cmegroup.com | 利下げ／利上げ確率の織り込み |
| FRED | fred.stlouisfed.org | マクロ経済の歴史データ |
| 米財務省 | home.treasury.gov | 国債入札計画、財政収支 |
| BLS | bls.gov | 雇用、CPI等の核心データ |
| BEA | bea.gov | GDP、PCE等の核心データ |

**第二段階: テーマ選別**

以下の基準で当日のテーマを絞り込む:
1. **市場の関心度**: そのデータ／イベントは当日の取引の主要なドライバーか？
2. **予想差**: 実績値と市場予想の乖離はどれほどか？乖離が大きいほど深掘り価値がある
3. **トレンドシグナル**: そのデータは中期トレンドを確認／反転させるものか？
4. **次の一手への影響**: FRBの次の判断への影響はどれほど大きいか？

**選別結果:**
- **A級テーマ** (必ず解説): 2条件以上を満たす → 5-8分で深掘り
- **B級テーマ** (任意で解説): 1条件を満たす → 2-3分で簡述
- **C級情報** (アーカイブ参照): 背景情報、トレンドが明確な時に使用

**解説フレームワーク:**
```
[背景] このデータ／イベントとは何か？(30秒、平易な言葉)
[データ] 前回値 vs 予想 vs 実績 (15秒)
[市場反応] データ発表後、市場はどう動いたか？(30秒)
[深層解読] なぜ重要か？次の一手は何を意味するか？(2-3分)
[歴史比較] 同様の状況は過去に何度あったか？その後市場はどう動いたか？(1分)
[結論] 個人投資家にとって何を意味するか？(30秒)
```

### C. 大手リサーチ精選 (5-8分) — 影響力主導

#### 核心理念: 網羅を追わず、精度を追う

**選別基準:**

1. **アナリストの影響力**:
   - TipRanks勝率 > 65%
   - 過去に重大な転換点を的確に予測
   - 大手チーフストラテジスト (ゴールドマン Jan Hatzius、モルガン・スタンレー Mike Wilson など)

2. **レポートの市場影響力**:
   - 発表後に関連銘柄に明確な変動
   - 市場コンセンサスと鮮明な対立
   - 当日注目のセクター／銘柄に関連

3. **コンテンツ価値**:
   - 独自のデータや分析フレームワークを含む
   - コンセンサスの単なる繰り返しでなく、新たな視点を提供
   - 個人投資家にとって教育的価値がある

**解説フレームワーク:**
```
[アナリスト背景] 誰が書いたか？どの機関か？過去の勝率？(30秒)
[核心見解] レポートは何を述べているか？(レーティング変更、目標株価調整) (30秒)
[重要論拠] 見解を支える1-2個の核心ロジック (1-2分)
[大手目標株価] 具体的目標株価＋現在株価 vs 目標株価の上値余地 (30秒)
[当番組の判断] この見解は妥当か？盲点はどこか？(1分)
[アクション指針] このリサーチに基づく、具体的買い建て／縮小戦略 (1分)
```

### D. 個別株／セクター深層分析 (10-15分) — 核心コーナー

#### 核心理念: 業界が違えば、測る物差しも違う

#### 業界分類とバリュエーション方法論

##### タイプ1: 高成長期 (AIインフラ、先端半導体、量子コンピューティング等)

**特徴**: 売上高が高速成長(前年比>30%)、未黒字または微黒字の可能性、巨額のCAPEX

**適用バリュエーション手法:**
| 手法 | 適用場面 | 主要指標 |
|------|----------|----------|
| PSR (株価売上高倍率) | 売上はあるが利益なし | Forward Revenue Multiple |
| P/FCF | CAPEXが巨大、FCFがマイナスの可能性に注意 | CAPEX口径の調整 |
| EV/Revenue | 企業間比較 | Enterprise Value / NTM Revenue |
| TAM浸透率 | 市場が巨大 | 現在の浸透率 vs 潜在TAM |
| ユニットエコノミクスモデル | SaaS／プラットフォーム型 | CAC, LTV, NRR, Rule of 40 |
| 遠期利益割引 | 明確な黒字化パスがある | 3-5年後の予想EPSの割引 |

**解説の重点:**
- 当期PEに固埢せず、売上成長率、顧客増加、シェア変化に焦点
- TAMの拡大または縮小を強調
- 技術的堀 (CUDAエコシステム、先端プロセス優位など) を注視
- 歴史的類推 (2000年代初頭のシスコ、2010年代のAWSなど)

##### タイプ2: 成熟成長期 (大型テックプラットフォーム、SaaSリーダー等)

**特徴**: 売上高が安定成長(前年比10-25%)、利益率が高め、明確な黒字

**適用バリュエーション手法:**
| 手法 | 適用場面 | 主要指標 |
|------|----------|----------|
| 予想PE | 利益が安定 | NTM EPS |
| PEGレシオ | 成長とバリュエーションの整合性 | PE / 予想EPS成長率 |
| DCF | キャッシュフローが予測可能 | WACC, Terminal Growth |
| EV/EBITDA | 資本構造をまたぐ比較 | Adjusted EBITDA |
| ユーザー／加入者価値 | プラットフォーム型 | ARPU, Churn, DAU/MAU |

##### タイプ3: シクロ銘柄 (エネルギー、素材、工業、海運等)

**特徴**: 利益が経済サイクルに伴い大きく変動、ピーク時のPEが非常に低い (それはまさに売りシグナル!)

**適用バリュエーション手法:**
| 手法 | 適用場面 | 主要指標 |
|------|----------|----------|
| 標準化PE | サイクル平滑化 | 過去5-7年平均利益 |
| PBR | 重資産業業種 | 帳簿価額の調整 |
| サイクル位置指標 | 転換点の判断 | 在庫サイクル、稼働率 |
| 配当利回り | 下値保護 | 過去の配当利回りレンジ |

##### タイプ4: ディフェンシブ／インカム型 (公益事業、生活必需品、ヘルスケア、REIT等)

**適用バリュエーション手法:**
| 手法 | 適用場面 | 主要指標 |
|------|----------|----------|
| DDM | 安定配当 | 配当成長率 |
| P/FFO | REIT | Funds From Operations |
| 利回り格差分析 | 債券的属性 | 国債利回りとの対比 |

#### 深層分析テンプレート (アクション指針を含む)

```
[セクター／個別株概要] 本日なぜこれを注目するのか？(1分)
[業界の位置付け] ライフサイクルのどの段階か？どの物差しで測るか？(1分)
[核心データ] 最も重要な3-5個の指標と推移 (3分)
[競争環境] モート分析、シェア変化 (2-3分)
[バリュエーション判断] 現在価格は歴史／同業の中でどの水準か？(2分)
[大手見解] 各大手の目標株価の集計＋レーティング分布 (1分)
[アクション指針] 具体的な買い建て／積み増し・縮小／損切り価格 (2分)  ← 鉄則二
[リスク要因] 最大の下値リスクは何か？(1-2分)
[まとめ] 一言で投資ロジックを (30秒)
```

#### 大手目標株価集計テンプレート

個別株を分析する際、都度以下を集計：
```
現在株価: $XXX

| 投資銀行 | レーティング | 目標株価 | 現株価比 | 核心ロジック |
|----------|-------------|----------|----------|--------------|
| ゴールドマン | 買い | $XXX | +XX% | [一言] |
| バンク・オブ・アメリカ | 買い | $XXX | +XX% | [一言] |
| モルガン・スタンレー | 中立 | $XXX | +XX% | [一言] |
| シティ | 買い | $XXX | +XX% | [一言] |

コンセンサス目標株価: $XXX (中央値)
最高目標株価: $XXX ([投資銀行名])
最低目標株価: $XXX ([投資銀行名])
```

#### アクション指針の出力規範
