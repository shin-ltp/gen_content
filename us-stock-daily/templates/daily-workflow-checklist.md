# 毎日制作フロー チェックリスト

> 印刷して作業場に貼るか、常時表示して手順通りに実行
> 本チェックリストは人間の制作補助用です。エージェント中心の多段階ワークフロー（Phase 0〜5）は [phases/overview.md](../phases/overview.md) を参照。本リストの「フェーズ1/2/3」は概ね Phase 0 / Phase 1-2 / Phase 4-5 に対応します。
> 収集時のスクリーンショットは必須ではありません（後段 Phase 3 での遅延取得でも可）。原則は「宁可多取也不漏掉（多く取り過ぎても漏らさない）」— まずテキスト＋URLで幅広く集めること。

### ステップ6: 本日のテーマ選定 [10分]
- [ ] Bセクション確認: 組み込むか？どのテーマ？
- [ ] Cセクション確認: 組み込むか？どのレポート？
- [ ] Dセクション確認: どのセクター/個別株？

  - 参考: 最近継続的に注目されているテーマ
  - 参考: 重大イベント(決算/製品発表)がある銘柄
- [ ] テーマ選定完了 → 制作開始

## フェーズ2: コンテンツ制作

> **※ 正式なコーナー構成は A → B → C → D（[../spec/content-framework.md](../spec/content-framework.md)）。下記 B〜F セクションは制作作業の便宜上の細分であり、実際にはすべて **B（メインテーマ・約30分）** に統合される（B=マクロ／C=リサーチ／D=個別株深層分析／E=戦略リスク は B 内のトピック、F=ニュースは C に相当）。ひな形は [daily-template.md](./daily-template.md)。

### Aセクション: オープニング（前日総括＋核心予告） [10-15分]
> 旧 OP（俳句）は A に統合。**俳句は任意の表現形式**。指数の流水帳は廃止（[../spec/content-framework.md](../spec/content-framework.md) / 鉄則一）。
- [ ] 全セクションの素材を確認し、Phase 1 の選題原則（[../phases/phase1-triage.md](../phases/phase1-triage.md)）で **3-5 話題** を確定
- [ ] 前日市況を**自然言語**で1-2文に総括（指数羅列しない）
- [ ] 各話題を**問い形式で1文ずつ**予告（路線図提示）
- [ ] （内容が俳句で凝縮できる時のみ）5-7-5調に練り上げ＋視覚デザインKW記録

### Bセクション: マクロ深層分析 [20-30分] (組み込む場合)
- [ ] 解説フレームワークに従い執筆
- [ ] 歴史比較データを準備

### Cセクション: 大手レポート [15-20分] (組み込む場合)
- [ ] 解説フレームワークに従い執筆
- [ ] アナリスト勝率を調査

### Dセクション: 深層分析 [30-45分]
- [ ] 業界タイプ確認 → バリュエーション方法選択
- [ ] sector-valuation-guide.mdを参照
- [ ] 核心データを収集
- [ ] 分析内容を執筆
- [ ] 交差検証を完了

### Eセクション: 投資戦略とリスク管理 [10-15分]
- [ ] 当日テーマと結びつけて執筆
- [ ] 達人の名言を追加

### Fセクション: ニュース振り返り [10分]
- [ ] モーニングレターから8本抽出
- [ ] 各30字以内に圧縮
