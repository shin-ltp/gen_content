## 三、内容展开方法论

**每个深度话题的展开公式:**

```
① 数据/事件开场 (抛出事实)
② 提出核心问题 (制造悬念)
③ 引用权威来源 (2-3个交叉验证)
④ 主持人独立解读 (个人判断)
⑤ 投资含义/操作建议 (实操落地)
⑥ 风险提示 (合规+诚实)
```

**数据驱动叙事规则:**
- 每个论点必须有具体数字支撑 (百分比、金额、倍数)
- 数据要有对比维度 (历史vs当前、A公司vs B公司)
- 百分比数据密度: 平均每27秒出现1个百分比 (23分钟51个)

**多源交叉验证规则:**
- 同一话题至少引用2个不同权威来源
- 正反观点并呈 (鹰派vs鸽派、看多vs看空)
- 明确标注信息来源，不模糊归因

**主持人角色四重定位:**
1. **信息整合者** — 汇总多个来源核心观点，节省观众时间
2. **独立思考者** — 表达个人判断，不模棱两可
3. **实操指导者** — 给出可操作的投资建议和具体策略
4. **风险守护者** — 每个建议都附带风险提示和历史反面案例

## 五、语言风格规范

- **口语化但不失专业**: 避免书面腔，像跟朋友聊天一样讲专业内容
- **适度幽默和情绪**: "希望他们明天死得惨一点" — 真实不装
- **直接表达观点**: 不说"可能也许大概"，说"核心还是得看通胀"
- **适当自嘲**: "当然，我是在瞎猜" — 降低防御心理
- **行业术语即用即释**: 出现专业词汇后立即用通俗语言解释
- **互动用语克制**: 全片仅6次"大家"，不刻意讨好观众

## 七、视觉呈现方法论 (画面分析)

> 基于 Vision API 对24帧关键截图的精确画面分析。

### 7.1 基础画面规格
| 参数 | 数值 |
|------|------|
| 分辨率 | 854×480 (16:9) |
| 帧率 | 标准30fps |
| 字幕 | 内嵌中文字幕（底部区域，白色字体） |
| 人物出镜 | 无（纯图文PPT风格+画外音旁白） |
| 署名 | 右下角标注"—— Jason/Steven 的观点" |

### 7.2 两套视觉风格系统 + 一套专栏

| 风格 | 适用场景 | 背景色 | 文字色 | 典型章节 |
|------|----------|--------|--------|----------|
| **明亮新闻风** | 开场市场速览、快讯 | 米白/浅奶油色 | 深绿边框+红绿涨跌色 | sec2 (今日市场速览) |
| **黑板观点风 (BLACKBOARD)** | 深度分析、个人观点、结论 | 深墨绿色 | 亮黄标题+白色正文 | sec4/sec5/sec6 (研报解读+观点) |
| **左图右文混合** | 公司/事件深度分析 | 左深右浅(分割) | 红色强调数字+绿色来源标注 | sec4 (Anthropic估值分析) |

### 7.3 画面布局规则

**模块化网格布局 (从上到下分层)**：
```
┌───────────────────────────────────────┐
│  频道标识(BLACKBOARD·黑板观点)  主标题  │  ← 顶部: 品牌+标题(最大字号)
├──────────────┬────────────────────────┤
│              │  来源标注(绿色小字)      │
│  配图/品牌图  │  主论点(红/黄色大字)    │
│  或 Logo     │  核心数据列表           │
│  或概念图    │  (红色=关键数字)        │
│              │  (黑色=描述性文字)      │
├──────────────┴────────────────────────┤
│  署名(右下角) │ 内嵌字幕(底部白色)    │  ← 底部: 字幕+署名
└───────────────────────────────────────┘
```

**两种构图模式**：
- **全幅卡片式** (市场速览): 3层并列模块 — 指数数据→板块涨跌对比→其他市场+关键点摘要
- **左图右文式** (深度分析): 左40%放品牌图/概念图，右60%放文字论述

### 7.4 文字呈现技巧

| 技巧 | 具体做法 | 效果 |
|------|----------|------|
| **中英双语** | "标普 · S&P 500" 格式 | 照顾中文观众+保留专业术语 |
| **颜色编码数字** | 关键数值用红色加粗，描述用黑色 | 视觉焦点锁定核心数据 |
| **符号辅助** | ▲ 领涨 / ▼ 领跌 | 直观指示涨跌方向 |
| **来源标注** | 左上角绿色小字 "媒体观点 · SemiAnalysis" | 信源背书但不喧宾夺主 |
| **字幕同步** | 底部白色字幕与旁白同步 | 辅助听觉+可静音观看 |
| **署名机制** | 右下"—— Jason/Steven 的观点" | 区分客观数据与个人观点 |

### 7.5 颜色语义系统

| 颜色 | 用途 | 使用场景 |
|------|------|----------|
| 深墨绿 | 背景底色 | BLACKBOARD专栏(模仿黑板) |
| 亮黄色 | 标题+强调 | 主论点、重点文字(荧光笔效果) |
| 红色 | 关键数字+警示 | 核心估值数据、下跌数字、风险信号 |
| 绿色 | 来源标注+上涨 | 信息出处、市场上涨数字 |
| 白色 | 正文+字幕 | 正文列表、底部字幕 |
| 米白/奶油 | 背景 | 明亮新闻风格(柔和纸质报告感) |
| 浅绿/浅粉 | 色块分类 | 领涨板块(绿底) vs 领跌板块(粉底) |

### 7.6 数据展示方式

该频道**不使用传统图表**（无K线、折线、柱状图），而是：

1. **纯数字 + 颜色编码**: 如 S&P -0.28% (红色), NASDAQ +0.20% (绿色)
2. **色块分类**: 浅绿色块=领涨板块列表, 浅粉色块=领跌板块列表
3. **逻辑递进列表**: 数据按逻辑层层推进 (现状→增速→预测→估值推导)
4. **象征性配图**: 用品牌Logo/概念图替代数据图表(如比特币+警告带=风险隐喻)
5. **文字化数据**: "历史多次下跌超80%" — 直接陈述结论而非展示原始数据

### 7.7 画面切换节奏

| 章节 | 节奏特征 | 画面持续时长 |
|------|----------|------------|
| 市场速览(sec2) | 单一卡片持续展示，信息密集 | 60-90秒/画面 |
| 研报解读(sec4) | 有画面切换/动画过渡 | 15-30秒/画面 |
| 半导体分析(sec5) | 单一信息图持续 | 30-60秒/画面 |
| 结论/警示(sec6) | 风格切换(暗→亮+红色)作为转场锚 | 10-20秒/画面 |

### 7.8 画面呈现方法论总结

1. **PPT幻灯片风格**: 纯图文+画外音，零出镜成本，画面完全服务信息传达
2. **按内容类型切换风格**: 快讯用明亮卡片风(降低门槛)，深度分析用黑板风(营造专业感)
3. **左图右文标准构图**: 左侧放品牌图/概念图作为视觉锚，右侧放文字论述
4. **颜色编码一致性**: 红=关键/警示, 黄=强调/重点, 绿=来源/上涨, 观众形成条件反射
5. **署名区分立场**: 客观数据无署名，个人观点标注"—— Jason的观点"
6. **不用传统图表**: 纯数字+颜色编码+列表，比图表更直觉、更适合小屏观看
7. **字幕+署名固定位**: 底部字幕区+右下署名区，位置恒定不变
