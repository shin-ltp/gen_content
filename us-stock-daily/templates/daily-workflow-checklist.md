# 毎日制作フロー チェックリスト

> 印刷して作業場に貼るか、常時表示して手順通りに実行
> 本チェックリストは人間の制作補助用です。エージェント中心の多段階ワークフロー（Phase 0〜5）は [phases/overview.md](../phases/overview.md) を参照。本リストの「フェーズ1/2/3」は概ね Phase 0 / Phase 1-2 / Phase 4-5 に対応します。
> 収集時のスクリーンショットは必須ではありません（後段 Phase 3 での遅延取得でも可）。原則は「多く取り過ぎても漏らさない」— まずテキスト＋URLで幅広く集めること。
> 収集の締めは `node tools/collect/collect-all.mjs`（自動 manifest 生成＋Gate #0 判定）。**Gate #0 不合格時は exit 2 で後段に進めない**。不合格項目を解消して再実行するか、`--no-gate` はデバッグ専用としてのみ使う。

## フェーズ2: コンテンツ制作

> **※ 正式なコーナー構成は A → B → C → D（[../spec/content-framework.md](../spec/content-framework.md)）。下記 B〜F セクションは制作作業の便宜上の細分であり、実際にはすべて **B（メインテーマ・25-40分）** に統合される（B=マクロ／C=リサーチ／D=個別株深層分析／E=戦略リスク は B 内のトピック、F=ニュースは C に相当）。ひな形は [daily-template.md](./daily-template.md)。

### Aセクション: オープニング（核心予告＋前日総括） [10-15分]
> 俳句は 2026-09-17 廃止。指数の流水帳は廃止（[../spec/content-framework.md](../spec/content-framework.md) / 鉄則一）。
>
> 2026-09-17 以降は末尾に **END-card → END-disclaimer** の順で 2 枚の固定スライドを置く。
> fixed ending の `endCardAtSec` で免責画面から END-card へ切替える。内容スライドは s1 から連続採番する。
- [ ] 冒頭に固定の番組紹介「ようこそ、毎日米国株式の市場分析をお届けするSmart Assets米国株投資チャンネルです。」を置く
- [ ] 全セクションの素材を確認し、Phase 1 の選題原則（[../phases/phase1-triage.md](../phases/phase1-triage.md)）で採用テーマ数 **N（3-5・固定しない）** を確定
- [ ] 前日市況を**自然言語**で1-2文に総括（指数羅列しない）
- [ ] 各テーマを **20字以内短标题＋80字以内简介** で予告し、TTSの `短标题[pause short]简介` を確認
- [ ] 予告 A-p1..A-pN の N と締め固定句の N が一致することを確認
- [ ] S0 は固定タイトルカードであることを確認（`assets/opening.png` 背景＋ロゴ・チャンネル名・タイトル。テーマ一覧页にしない）

## フェーズ3: 仕上げ

- [ ] 全文を通読、データ正確性を確認
- [ ] 人物写真を素材種別で判定する。当該ニュース配図・講演・会見の実写は split 全幅、プロフィール写真は必ず `slide profile` の円形・左側垂直中央にする
- [ ] プロフィール写真のページは Playwright などで少なくとも1枚截図し、氏名表示・本文・テーマチップが左側写真に重ならないことを確認する
- [ ] S0 と s1 のスクリーンショットを確認する。S0 は固定タイトルカード、s1 はタイトルだけの一覧1枚で简介が漏れていないこと
- [ ] 免責文が `END-disclaimer` 静止画のみで、script.json / draft-* / tts txt に0件であることを確認
- [ ] 末尾のエンディング挨拶（固定文言。次回が休場なら休場予告を1文挿入）があることを確認
- [ ] データ出所を明記
- [ ] 制作総時間を記録 (フロー最適化のため)
