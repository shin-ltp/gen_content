## 一、視覚レイアウトの種類（全6タイプ）

美投侃新聞の番組では、コンテンツの種類に応じて以下の6つの視覚レイアウトが使い分けられている。

### Layout 1: オープニング・タイトルカード

**対応コーナー**: オープニング（番組開始）
**特徴**:
- 全画面背景画像（ブランドイメージまたは抽象的な金融イメージ）
- 中央に番組タイトルと日付を大きく配置
- チャンネルロゴは左上または中央上部
- 色調は暗めで高級感（濃紺〜黒のグラデーション）
- テキストは白または金色

**使用シーン**: 番組の開始、ブランドアイデンティティの確立

---

### Layout 2: 市場速報カード（全画面カード式）

**対応コーナー**: A.③ 前日市況の総括
**特徴**:
- 背景: オフホワイト/ライトクリーム (#FAF6EE)
- 3層構造:
  1. **三指数カード**: S&P 500, NASDAQ, DOWの3枚を横並びで配置。騰落率を大字で表示
  2. **セクターブロック**: 左=値上がりセクター（ライトグリーン #E8F5E9 + ▲）、右=値下がりセクター（ライトピンク #FCE4EC + ▼）
  3. **その他市場バー**: 深緑の横棒にビットコイン、金、石油、国債などの資産名と変動を並記
  4. **本日の要点**: 2-3条の箇条書き
- 数字の色コーディング: 赤=下落、緑=上昇
- テキスト中心、チャート不使用

**使用シーン**: 市場データの快速スキャン、毎日同じ構造で視認性を確保

---

### Layout 3: 本日の目玉予告（縦リスト+ハイライト）

**対応コーナー**: A.② 本日の目玉内容の予告
**特徴**:
- 背景: オフホワイト/クリーム
- 縦箇条書きで3-5のテーマタイトルを表示
- 左側にテーマごとの素材画像（企業ロゴ/概念図）を配置
- 話しているテーマのタイトルを**黄背景でハイライト**、他はグレーダウン
- アニメーション: 話題が進むごとにハイライトが移動

**使用シーン**: 番組の構造を視聴者に示す、期待感を醸成

---

### Layout 4: 深層分析（左図右文式）

**対応コーナー**: B. メインテーマ
**特徴**:
- 背景: 濃紺 (#0A1628) または深緑 (#0F3D2E) — ブラックボード風
- **左40%**: ブランド図/概念図/企業ロゴをビジュアルアンカーとして配置
- **右60%**: テキスト論述
  - 情報源標注: 左上に緑色小文字
  - メイン論点: 明るい黄色の見出し（蛍光ペン効果）
  - 核心データ: 赤色太字
  - 説明テキスト: 白色
- 1つのテーマを複数スライドに分割（15-30秒/画面）
- 結論画面はスタイル切替（暗→明+赤）でアンカー化

**使用シーン**: マクロ経済分析、個別株深層分析、バリュエーション解説

---

### Layout 4b: 深層分析・全画面チャート版

**対応コーナー**: B. メインテーマ（データ量が多い回、外部チャートを使用する回）
**特徴**:
 - 左の画像アンカーを廃止し、**画面全体を情報表示に使う拡張レイアウト**
 - 上部: 情報源 + 見出し + 出典バッジ
 - 中央左: 外部コンテンツ（TradingView / 決算資料 / 表など）表示エリア
 - 右側: 3枚の統計カード（大きな等幅数字 + 短い説明）で要点を固定表示
 - **切替ルール**: 通常の論述は Layout 4、右側の論述が収まらない・チャートを見せたい場合は Layout 4b に自動切替
 - **外部コンテンツ背景色適応**:
   - 明るい背景（白系チャート・資料）→ 白カードとして配置し影で浮かせる
   - 暗い背景（ダークモードチャート）→ 枠線のみで紺背景に直接統合
   - 制作パイプライン側でデータソースの背景色を判定し、自動選択する

**使用シーン**: 金利先物の確率カーブ、決算ヒストグラム、複数指標の比較、長文の要約が同時に必要な分析

---

### Layout 5: ニュースハイライト（箇条書きカード）

**対応コーナー**: C. News Highlights
**特徴**:
- 背景: オフホワイト/クリーム
- 8本のニュースタイトルを全画面カードでリスト表示
- 放送中のニュースタイトルを**黄背景でハイライト**、他はグレーダウン
- 各タイトルは30字以内
- テンポ速め（速報感）

**使用シーン**: 短時間での複数ニュース伝達、速報性重視

---

### Layout 6: 免責事項・エンディング（低彩度フッタ）

**対応コーナー**: 免責事項、エンディング
**特徴**:
- 背景: グレー系または薄オフホワイト（落ち着いたトーン）
- 中央寄せの短文
- 本文サイズ・ダークカラー
- 読みやすさ優先、装飾最小
- フェードインのみ

**使用シーン**: コンプライアンス対応、番組の締めくくり

## 二、レイアウト使い分けの法則

| コンテンツタイプ | レイアウト | 背景トーン | 情報密度 | アニメーション |
|----------------|-----------|-----------|---------|---------------|
| ブランド/開始 | Layout 1 | 暗い | 低 | フェードイン |
| データ一覧 | Layout 2 | 明るい | 高 | スライドイン |
| 予告 | Layout 3 | 明るい | 中 | ハイライト移動 |
| 深層分析 | Layout 4 | 暗い | 高 | フェード/スライド |
| 速報 | Layout 5 | 明るい | 中 | ハイライト移動 |
| 法的事項 | Layout 6 | 中性 | 低 | フェードイン |

**パターン**:
- **速報・一覧 → 明るい背景**（オフホワイト/クリーム）: 親しみやすい、読みやすい
- **深層分析・見解 → 暗い背景**（濃紺/深緑）: 専門感、高級感、集中力
- **遷移のアンカー**: 暗→明のスタイル切替はコーナー転換点で使用

## 三、共通デザイン要素

### 3.1 色セマンティックシステム

| 色 | 役割 | HEX | シーン |
|----|------|-----|--------|
| 赤 | キー数字・警告・下落 | #D32F2F | バリュエーションデータ、下落数字、リスク |
| 緑 | 情報源・上昇 | #2E7D32 | 出所表示、市場上昇 |
| 黄 | 強調・見出し | #FBC02D | メイン論点、重点テキスト |
| 白 | 本文・字幕 | #FFFFFF | 本文リスト、字幕 |
| 濃紺 | 背景（深層） | #0A1628 | ブラックボード系 |
| 深緑 | 背景（深層） | #0F3D2E | ブラックボード系 |
| オフホワイト | 背景（ニュース） | #FAF6EE | 明るいニュース風 |
| 金 | 俳句アクセント | #D4AF37 | 俳句の文字 |

### 3.2 タイポグラフィ

| 用途 | フォント | 備考 |
|------|---------|------|
| 本文・見出し | Noto Sans JP / 游ゴシック | ゴシック系、太字で階層表現 |
| 俳句 | Noto Serif JP / 游明朝 | 明朝系、高級感 |
| 数値 | 等幅（タブラー）フォント | 桁揃え |

### 3.3 固定要素

- **字幕**: 下部エリア、白色フォント、ナレーションと同期
- **署名**: 右下「—— 当チャンネルの見解」（個人見解の画面のみ）
- **情報源標注**: 左上、緑色小文字（例: "メディア見解 · SemiAnalysis"）

## 五、設計上の注意事項

1. **チャート不使用**: 伝統的なチャート（ローソク足、折れ線、棒グラフ）は使わない。純数字+色コーディングで対応
2. **色の一貫性**: 赤=下落/警告、緑=上昇/情報源、黄=強調の役割を必ず維持
3. **フォント選択**: 日本語視聴者向けのため、Noto Sans JP / Noto Serif JP を推奨
4. **署名の使い分け**: 客観データには署名なし、個人見解には署名あり
5. **画面持続時間**: 高密度カード 60-90秒 / 解説スライド 15-30秒 / 結論 10-20秒
