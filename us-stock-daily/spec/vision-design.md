## 0. グローバルデザインシステム（共通基盤）

### 0.1 基礎画面仕様

| パラメータ | 仕様 |
|-----------|------|
| 解像度 | **1920×1080**（16:9）。縮小配信時もこの比率を維持 |
| 番組名 | 角ヘッダーは**【Smart Assets 米国株】**、正式チャンネル名は**【Smart Assets 米国株投資チャンネル】**。参考番組名（美投・美投侃新聞）は画面へ出さない |
| 人物出演 | **なし**（純図文＋ナレーションのPPTスライドスタイル） |
| 字幕 | 下部エリアに日本語字幕（白色フォント・ナレーションと同期） |
| 署名 | 個人見解は本文内ラベル（「当番組の見解」等）で明示。**画面フッター行・右下署名行は設けない**（2026-08-27 改訂） |
| 全体基調 | 美投侃新聞のデザインを規範とする（高級感・情報密度重視・出演コストゼロ） |

> **共通ヘッダー（2026-08-27 改訂）**: 各画面の角ヘッダー（**ロゴ＋Smart Assets 米国株**）は**右下に統一配置**する（テーマ見出しとの混雑を避けるため右上には置かない。オープニングタイトルカードを除く）。日付チップ・コーナー名チップなどのページラベルは**表示しない**。A-1 / B-2 / C 等の**テンプレ構成名を画面に出さない**（編集上の小見出し「発端」「歴史比較」等は可）。**画面フッター行（出所・注釈・ページ番号）は設けない**。
>
> **出所表示（2026-09-03 改訂）**: 出所は**画像・チャートの左下部キャプションのみ**に表示し、本文・データカード・注釈列には出所行を設けない。**当番組自作の概念図・図は出所キャプションを表示しない**。外部取得の写真・人物写真・チャートは取得元を出所に明記する。**WallstreetCN 等の中国語ソースは画像・チャートの場合も含めて一律非表示**とする。
>
> **B テーマ見出し（2026-08-28 改訂）**: B セクションは 1 テーマを複数画面で展開するため、**テーマ見出しチップ**（例: `テーマ①｜長期金利と半導体急落`）を表示し、今どのテーマの話かを常時示す。チップは**画面最上部のヘッダー行に固定**し、**本文列の左端に揃える**（左図右文ページでは右コンテンツ列の左端）。上下中央配置の対象は**小見出し→タイトル→本文のみ**（チップを含めない）。**中央配置の計算領域はヘッダー行の下端（約110px）から下部ロゴ帯まで**とし、ヘッダー行の高さを含めない（内容が多いページでチップと本文が重ならないようにする）。小見出し→タイトル→本文の間隔は固定とし、タイトル直下の空白が日によって膨らまないよう本文側の独自中央寄せはしない。
>
> **オープニングタイトルカード＝YouTubeサムネイル（2026-08-28 改訂）**: S0 は YouTube のサムネイルを兼ねる。**大型ロゴ＋チャンネル名（Smart Assets 米国株投資チャンネル）＋メインタイトルを横並びのロックアップ**（ロゴは左端、チャンネル名はタイトル直上）で画面中央に配置し、角ヘッダーは置かない。タグライン等の補足は付けず、**モバイルの一覧表示でも読める文字サイズと高コントラスト**を最優先する。
>
> **S0 固定背景（2026-09-01 改訂）**: S0 の背景画像は**全エピソード共通で `opening-visual.png`（ウォール街の夜景＋赤緑 K 線光軌）**に固定する。日次の概念図（jackson-hole 等）を S0 背景に流用しない。Phase 3 は [`assets/brands/template/opening-visual.png`](../assets/brands/template/opening-visual.png) を当該回の `assets/concepts/opening-visual.png` へコピーし、visual.html は `<img src="assets/concepts/opening-visual.png">` で参照する（相対パス解決のため各日コピーを必須とする）。

### 0.2 2系統のビジュアルスタイル

コンテンツタイプに応じて切り替える。これが画面の「温度」を決める。

| スタイル | 適用シーン | 背景色 | 文字色 | 対応コーナー |
|---------|----------|--------|--------|--------------|
| **明るいニュース風** | 速報・一覧・予告 | オフホワイト／ライトクリーム | ダークカラー地＋赤緑の騰落色 | A.②/③・C・D |
| **ブラックボード深層分析風** | 深掘り解説・個人見解・結論 | 濃紺 または 深緑 | 明るい黄色の見出し＋白色の本文 | A.①(俳句)・B |

### 0.3 カラーシステム（セマンティック色）

色は「役割」で定義し、一貫して運用することで視聴者に条件反射を形成する。

| 役割 | 色 | HEX（目安） | 使用シーン |
|------|----|------------|-----------|
| キー数字・警告・下落 | 赤 | `#D32F2F` | 核心的バリュエーションデータ・目標株価・下落数字・リスクシグナル |
| 情報源・上昇 | 緑 | `#2E7D32` | 出所表示・市場上昇数字 |
| 強調・見出し | 黄（蛍光ペン効果） | `#FBC02D` | メイン論点・重点テキスト |
| 本文・字幕 | 白 | `#FFFFFF` | 本文リスト・下部字幕 |
| 背景（深層分析） | 濃紺／深緑 | `#0A1628`／`#0F3D2E` | ブラックボード系背景 |
| 背景（ニュース） | オフホワイト／クリーム | `#FAF6EE` | 明るいニュース風背景 |
| 俳句アクセント | 金 | `#D4AF37` | 俳句の文字・装飾 |
| 分類ブロック | ライトグリーン／ライトピンク | `#E8F5E9`／`#FCE4EC` | 騰値上位（緑）vs 下落上位（ピンク）の色ブロック分類 |

### 0.4 タイポグラフィ

| 用途 | 書体 | 備考 |

### 0.5 画面レイアウトグリッド（モジュラー・3層構造）

```
┌───────────────────────────────────────────┐
│ 上部: 右上ロゴ＋番組名／メインタイトルは本文側       │
├─────────────────┬─────────────────────────┤
│  左: 配図（画面高100%・余白なし）                  │
│  ／概念図        │  メインタイトル／小見出し       │
│  出所は画像内    │  核心データリスト           │
│  下部に表示      │  （赤=キー数字／白=説明）    │
│   (40%)         │              (60%)        │
├─────────────────┴─────────────────────────┤
│ 下部: フッター行なし（字幕は動画編集で別途合成）    │
└───────────────────────────────────────────┘
```

**2つの構図パターン**（コーナーで使い分け）：
- **左図右文式**（深層分析 B 等）：左40%の画像は**画面高100%・左余白なし**で全面配置し、出所は画像内下部キャプションに表示。右60%にタイトルとテキスト論述。**フッター行は設けない**。
- **全画面カード式**（市場速報・ニュース C 等）：3層の並列モジュールで一覧表示。

### 0.6 チャート条件付き使用ルール（2026-08-28 改訂）

伝統的なチャート（ローソク足・折れ線・棒グラフ）は**既定では使わない**。ただし、以下の **4场景でのみチャートの使用を許可**する:

| # | チャート使用场景 | 例 |
|---|----------------|-----|
| 1 | **長期トレンドの提示** | 30年債利回りが19年ぶり高値に至る軌跡／SOX 指数の年初来推移 |
| 2 | **周期性・規則性の可視化** | 金利サイクルと株価パフォーマンスの周期／セクター・ローテーションの反復 |
| 3 | **歴史イベントとの対照** | 5大バブルのピーク局面の重ね合わせ／過去の利上げ局面との比較 |
| 4 | **複数指数・指標の相互作用分析** | 長期金利×半導体株の逆相関／ドル円×輸入インフレの連動 |

**チャート使用時の鉄則**:

- 軸・期間・単位・外部出所を必ず明記。出所は左画像内の下部キャプションに表示（§0.5 共通ルール準拠）。当番組自作チャートは出所キャプション不要、中国語ソース由来は出所非表示
- **1画面1メッセージ**。チャートが示す結論を右コンテンツのテキストで近接提示し、「何を言いたい図か」が一目で分かるようにする
- 1920×1080 に引き伸ばして鮮明な高解像度素材のみ（SVG または高解像度 PNG）
- 系列は原則 **2〜3本まで**。モバイル視認性を損なう密集図・多系列図は使わない

**純数字＋色ブロック＋段階リストを優先する场景**（チャートにしない）:

| # | 優先场景 | 表現方法 |
|---|---------|---------|
| 1 | 単一スナップショット値（本日の指数・騰落率・時価総額） | **純数字＋色コーディング**（例 `S&P -0.28%`（赤）） |
| 2 | 単純比較・順位（値上がり/値下がり筆頭、KPI 並列） | **色ブロック分類**（ライトグリーン=騰値上位、ライトピンク=下落上位） |
| 3 | 因果・論理の段階展開（割引率メカニズム等の説明） | **論理的段階リスト**（現状→成長率→予測→バリュエーション導出） |
| 4 | 分類・構造の提示（デュオカード、セクター分類） | **色ブロック＋小ロゴ**、概念図 |
| 5 | 短期変動・粒度が細かすぎるデータ | チャート化せず結論を直接陳述（**テキスト化データ**: 「過去に何度も80%超の下落」） |
| 6 | 象徴的に示せるもの | **象徴的配図**（ブランド実写・概念図でデータを代替） |

> **データ取得**: Phase 0 では従来どおりチャートを収集しない（記事内チャートはフラグのみ）。**視覚設計ブリーフでチャートが必要と判定された场景**に対し、**Phase 3 が能動的に検索・収集**する（履歴データ: Stooq／FRED／Yahoo Finance、既製チャート: 公式 IR・信頼できる金融メディアの高解像度スクリーンショット）。詳細は [../phases/phase3-asset-fetching.md](../phases/phase3-asset-fetching.md)。ロゴ・実写は引き続き共有キャッシュ [../assets/brands/](../assets/brands/) 優先。

### 0.7 共通アニメーション語彙とテンポ

| 効果 | 用途 | テンポ目安 |
|------|------|-----------|
| フェードイン | 句・見出しの登場 | 緩やか（俳句・結論） |
| スライドイン | リスト項目の逐次表示 | 中速（データリスト） |
| ハイライト強調 | 話中のテーマ/ニュースの注目 | 即時（話題と同期） |
| スタイル切替（暗→明＋赤） | コーナー転換のアンカー | 切替点で1回 |

画面持続時間の目安：高密度カード 60-90秒／解説スライド 15-30秒／結論 10-20秒。

### 0.8 画像レイアウトと使い分け（2026-08-31 参照例に基づく最終版）

**三つのレイアウトパターン**（参照例に基づく・2026-08-31 確定）:

| パターン | レイアウト | 使う場面 | 参照例 |
|---|---|---|---|
| **A. 発言・講演・イベント** | **左40% 全高竖版写真** + 右60% コンテンツ。標準 split | CEO講演、議長発言、決算会見 | 図1（ウォッシュ講台） |
| **B. 人物の見解・引用** | **円形ヘッドショット（320-400px）を左側垂直中央**、直下に氏名＋肩書き、右に見解 | アナリスト評価、エコノミスト主張 | 図2（ウォッシュ円形） |
| **C. テーマ概念・経済データ** | **左40% 全高** 概念イラスト/実景 + 右60% データ。split | 経済指標、行業、技術トレンド | 図3-5 |

> **重要**: パターンA（講演写真）は人物が写っていても split のまま。円形は「パターンB（見解引用）」専用。
>
> **B 版式の実装制約**: 円形アバター＋氏名の列は**必ず `<div class="visual">` で包む**こと。`.chrome` は `padding-left: calc(var(--img-width) + 54px)` を持つため、ラッパーなしで头像を `.body` の直下 flex 子要素にすると右コンテンツ内に崩れ込む（2026-08-28 s14 の不具合）。氏名・肩書きは円の下に置き、背景写真（photo-frame）は併用しない

| 表示コンテキスト | 使う画像（優先順） | 効果 | 主な適用先 |
|---|---|---|---|
| **人物の発言・講演** | ① 講演・会見の現場写真（竖版）→ ② ニュース添付 → ③ SearXNG「{氏名} speech」 | 誰が何を語っているか文脈ごと伝わる | **A（split 全高）** |
| **人物の見解引用** | ① 本人の高解像度ポートレート → ② Wikipedia | 「この人がこう言った」が即座に伝わる | **B（円形・垂直中央）** |
| **企業・機関の単独表示** | ① **社名・機関名が写り込む本社・代表的な建築物の高解像度実写** → ② 店舗・工場・施設の実写 → ③ Wikipedia インフォボックス → ④ SearXNG | リアリティ・説得力 | §4 B の個別株・機関 |
| **物理的オブジェクト**（半導体、DC、ロケット、小売店頭等） | ① **公式IR・ニュース記事の添付写真** → ② Wikipedia/Wikimedia Commons → ③ SearXNG 画像検索 → ④ なければ**生成**（但し実物に寄せる） | 具体性・情報量 | §4 B の技術・施設・製品説明 |
| **政府・中央銀行・財務省** | ① **機関の公式建築写真**（Eccles Building、Treasury Building等）→ ② **関係者の公式ポートレート** → ③ 議会・会見の報道写真 → ④ SearXNG | 権威・実在感 | §4 B の政策・マクロ |
| **アプリ・サービス画面** | ① **公式スクリーンショット**（App Store・Google Play・IR資料）→ ② 報道記事のスクリーンショット → ③ 自身で撮影した画面キャプチャ | 製品の実感 | §4 B の個別サービス解説 |
| **多品牌列挙**（一覧・比較・出所羅列） | 小さなロゴ（背景透過）を**補助的に**配置。可能な限り背景に薄い実写写真や質感のある色面を敷き、ロゴ単体でのっぺりさせない | 視認性＋統一感＋質感 | §2 目玉予告・§5 ニュース速報・セクター一覧 |
| **経済データ・行業概念** | テーマに応じた概念イラスト（下記スタイルガイド）または実景写真 | テーマの視覚的アンカー | **C（split 全高）** |

> **鉄則（2026-08-31 最終版）**:
> 1. **講演・發言写真は常に split（左全高）** — 人物が写っていても変更しない（参照図1）
> 2. **円形ポートレートは「見解引用」専用・垂直中央** — アナリスト評価ページでのみ使用（参照図2）
> 3. **経済データ・行業テーマは概念図 + split** — 主体が具体的企业でない場合に概念イラストを生成（参照図3-5）
> 4. **概念イラストのスタイル**: フラット/ベクター插画で具体的な物件に焦点。3Dレンダー・抽象的比喩は使わない
> 5. **同一画像の多用禁止・キーワード別ローテーション（2026-08-31 改訂）** — 内容キーワード（対象・指標・機関）が新たに変化した画面は、新しいキーワードで画像検索または画像生成を行う。同一概念図の使用は**1エピソードあたり最大 2 画面**まで。常用キーワード（債務・利回り・TGA・CPI・予測市場・決算等）は**複数バージョンの画像を共有ライブラリ [../assets/concepts/](../assets/concepts/) に蓄積し（manifest.md 登録）、回を跨いでローテーション**する
> 6. **ニュース記事の添付写真があれば最優先**
> 7. **ロゴは補助**
> 8. **ロゴの地色コントラスト** — 透過ロゴを写真枠に収める際、`background` をロゴの本体色と同系にしない（白抜きロゴ＋白背景は不可）。判別不能な場合はロゴを地色に合う色へ加工するか、**社名入りの本社実写写真に差し替える**（§0.8 企業単独表示の優先順に従う）。2026-08-28 s29（白抜き Salesforce ロゴ×白背景）を再発防止例とする
>
> 実写写真・報道写真の取得は [../phases/phase3-asset-fetching.md](../phases/phase3-asset-fetching.md) の取得フローに従う（公式ニュースルーム → Wikipedia → SearXNG 画像検索）。

#### Top slide・ページ画像の運用と素材採用の確定ルール（2026-09-08 新設）

**構成ルール**:

- **B セクション各テーマ = Top slide 1枚 + 分頁画像n枚**。テーマ先頭ページ（`B*-p0` 等）に使うメイン画像を「Top slide」と呼ぶ。
- **A.② 四問予告（S2）**: 左側の表示画像は**各 B テーマの Top slide 画像を輪換表示**する。読み上げが進むごとに対応テーマの Top slide へ切り替え、テーマごとにロゴや概念図を別途新規作成しない。
- **B の 2 ページ目以降**: 基本は **Top slide を沿用**する。語っている内容の主体（人物・企業・製品・標的）が大きく変わる場合にのみ、新しいページ画像へ差し替える。

**主体別の画像指定**:

| 話題の主体 | 採用する画像（優先順） |
|---|---|
| 財務省・FRB・政府高官の発言 | ① 官僚の講演・会見写真 → ② 機関の庁舎写真（Eccles Building 等） |
| 投資銀行・銀行の見解 | ① **知名アナリストの発言はそのアナリストの頭部写真（バストアップ）** → ② それ以外は**社名が視認できる建物実写写真** |
| 上場企業（創業者の発言） | **創業者の講演・発言写真**（最優先） |
| 上場企業（非創業者の発言） | 社名が視認できる建物実写写真 |
| 上場企業（分頁の製品・サービス内容） | 内容に連動した素材：アプリアイコン入り高品質画像・主要プロダクトのロゴ入り画面スクリーンショット等 |
| 指数・ETF・国債など個別標的 | **名称が確認できる高品質画像** |

**採用原則（検索と生成の棲み分け）**:

1. 実物・実在機関・実在人物が存在する題材は**必ず画像検索の結果を素材に採用**し、生成画像は使わない。
2. 高品質な画像が見つからない場合は、**キーワードを調整して再検索**する（例: `{氏名} speech`、`{社名} headquarters`、`{製品} app`）。複数回の再検索でも高品質素材が得られない場合にのみ、**最終手段として生成を検討**する。
3. 市場の動き・センチメント・マクロ指標の変化など、対応する実体・人物が存在しない題材に限り、**生成画像を許可**する。
