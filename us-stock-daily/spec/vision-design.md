# 視覚デザイン仕様（Vision Design）

> 番組の**視覚表示テンプレート**の定義。全体の色・画面レイアウト・アニメーション効果・画像スタイルを規定する。
> 内容（何を話すか）は [content-framework.md](./content-framework.md)。本章は**それをどう見せるか**。
> **本仕様の §1〜§7 は [../templates/daily-template.md](../templates/daily-template.md) の各部と1対1に対応する。**
> ベースラインの視覚方法論は [BENCHMARK_ANALYSIS.md](../BENCHMARK_ANALYSIS.md) 第七章を参照。

## 0. グローバルデザインシステム（共通基盤）

### 0.1 基礎画面仕様

| パラメータ | 仕様 |
|-----------|------|
| 解像度 | **1920×1080**（16:9）。縮小配信時もこの比率を維持 |
| 人物出演 | **なし**（純図文＋ナレーションのPPTスライドスタイル） |
| 字幕 | 下部エリアに日本語字幕（白色フォント・ナレーションと同期） |
| 署名 | 右下に「—— 当チャンネルの見解」（個人見解の画面のみ。客観データ画面には署名なし） |
| 全体基調 | 美投侃新聞のデザインを規範とする（高級感・情報密度重視・出演コストゼロ） |

### 0.2 2系統のビジュアルスタイル

コンテンツタイプに応じて切り替える。これが画面の「温度」を決める。

| スタイル | 適用シーン | 背景色 | 文字色 | 対応コーナー |
|---------|----------|--------|--------|--------------|
| **明るいニュース風** | 速報・一覧・予告 | オフホワイト／ライトクリーム | ダークカラー地＋赤緑の騰落色 | A.②/③・C・D |
| **ブラックボード深層分析風** | 深掘り解説・個人見解・結論 | 濃紺 または 深緑 | 明るい黄色の見出し＋白色の本文 | A.①(俳句)・B |

### 0.3 カラーシステム（セマンティック色）

色は「役割」で定義し、一貫して運用することで視聴者に条件反射を形成する。

| 役割 | 色 | HEX（目安） | 使用シーン |
|------|----|------------|-----------|
| キー数字・警告・下落 | 赤 | `#D32F2F` | 核心的バリュエーションデータ・目標株価・下落数字・リスクシグナル |
| 情報源・上昇 | 緑 | `#2E7D32` | 出所表示・市場上昇数字 |
| 強調・見出し | 黄（蛍光ペン効果） | `#FBC02D` | メイン論点・重点テキスト |
| 本文・字幕 | 白 | `#FFFFFF` | 本文リスト・下部字幕 |
| 背景（深層分析） | 濃紺／深緑 | `#0A1628`／`#0F3D2E` | ブラックボード系背景 |
| 背景（ニュース） | オフホワイト／クリーム | `#FAF6EE` | 明るいニュース風背景 |
| 俳句アクセント | 金 | `#D4AF37` | 俳句の文字・装飾 |
| 分類ブロック | ライトグリーン／ライトピンク | `#E8F5E9`／`#FCE4EC` | 騰値上位（緑）vs 下落上位（ピンク）の色ブロック分類 |

### 0.4 タイポグラフィ

| 用途 | 書体 | 備考 |
|------|------|------|
| 本文・見出し | ゴシック系（Noto Sans JP／游ゴシック） | 太字で階層表現 |
| 俳句 | **行書／明朝**（Noto Serif JP／游明朝／行書体） | 高級感・和の趣 |
| 数値・データ | 等幅（タブラー）フォント | 桁揃え・視認性 |
| バイリンガル | 日本語＋英語原文併記（「S&P 500／標普」形式） | 専門用語保持 |

### 0.5 画面レイアウトグリッド（モジュラー・3層構造）

```
┌───────────────────────────────────────────┐
│ 上部: ブランド標識 ＋ メインタイトル（最大フォント） │
├─────────────────┬─────────────────────────┤
│                 │  情報源標注（緑・小）       │
│  左: 配図／Logo   │  メイン論点（赤/黄・大文字）  │
│  ／概念図        │  核心データリスト           │
│   (40%)         │   （赤=キー数字／黒=説明）    │
│                 │              (60%)        │
├─────────────────┴─────────────────────────┤
│ 下部: 埋め込み字幕（白） ＋ 右下署名            │
└───────────────────────────────────────────┘
```

**2つの構図パターン**（コーナーで使い分け）：
- **左図右文式**（深層分析 B 等）：左40%にブランド図/概念図をビジュアルアンカー、右60%にテキスト論述。
- **全画面カード式**（市場速報・ニュース C 等）：3層の並列モジュールで一覧表示。

### 0.6 チャート不使用ルール（重要）

伝統的なチャート（ローソク足・折れ線・棒グラフ）は**使わない**。代わりに：

1. **純数字＋色コーディング** — 例 `S&P -0.28%`（赤）、`NASDAQ +0.20%`（緑）
2. **色ブロック分類** — ライトグリーンのブロック=騰値上位、ライトピンクのブロック=下落上位
3. **論理的段階リスト** — データを論理的に段階的に展開（現状→成長率→予測→バリュエーション導出）
4. **象徴的配図** — ブランドLogo/概念図でデータチャートを代替
5. **テキスト化データ** — 生データではなく結論を直接陳述（「過去に何度も80%超の下落」）

> 小画面視聴でも直感的。必要な画像・ロゴは Phase 3 で遅延取得（[../phases/phase3-asset-fetching.md](../phases/phase3-asset-fetching.md)）。ロゴは共有キャッシュ [../assets/brands/](../assets/brands/) 優先。

### 0.7 共通アニメーション語彙とテンポ

| 効果 | 用途 | テンポ目安 |
|------|------|-----------|
| フェードイン | 句・見出しの登場 | 緩やか（俳句・結論） |
| スライドイン | リスト項目の逐次表示 | 中速（データリスト） |
| ハイライト強調 | 話中のテーマ/ニュースの注目 | 即時（話題と同期） |
| スタイル切替（暗→明＋赤） | コーナー転換のアンカー | 切替点で1回 |

画面持続時間の目安：高密度カード 60-90秒／解説スライド 15-30秒／結論 10-20秒。

### 0.8 企業・メディア画像の使い分け（美投侃新聞スタイル）

企業・メディアを画面に出す時、**表示コンテキストで2種類を使い分ける**。素材は共有キャッシュ [`assets/brands/`](../assets/brands/) から（[../infra/brand-asset-cache.md](../infra/brand-asset-cache.md)）。

| 表示 | 使う画像 | 効果 | 主な適用先 |
|---|---|---|---|
| **単独表示**（1社/1媒体をクローズアップ） | **本社大楼・标志性建築物など社名・媒体名が入った実写写真**（`<slug>-hq.jpg`） | リアリティ・説得力。実在感 | §4 B の個別株深層分析 |
| **多品牌列挙**（一覧・比較・出所羅列） | **シンプルなロゴ**（`<slug>.png`・背景透過） | 視認性・統一感 | §2 目玉予告・§5 ニュース速報・セクター一覧 |

> 単独で1社を掘り下げる場面では、無機質なロゴではなく**社名の入った実写建築写真**をビジュアルアンカーに据えることで、解説の説得力と番組の質感が上がる。複数を並べる一覧場面では逆にロゴで統一して視認性を優先する。

## セクション別仕様（テンプレートと1対1）

> 各セクションは [../templates/daily-template.md](../templates/daily-template.md) の対応部と番号で揃える。

### §1. オープニング俳句　←　テンプレート A.①

| 項目 | 仕様 |
|------|------|
| スタイル | ブラックボード深層分析風（特別枠） |
| 背景 | **浮世絵・富嶽三十六景**（神奈川沖浪裏）。素材：[`assets/brands/template/The_Great_Wave_off_Kanagawa.jpg`](../assets/brands/template/The_Great_Wave_off_Kanagawa.jpg)。全体を暗くトーンダウンして文字を読みやすく |
| 文字 | **行書／明朝フォント**。色は**金**（`#D4AF37`）または**白**（`#FFFFFF`）。中央・大フォント |
| レイアウト | 全画面。句を中央に縦書きまたは横書きで配置。余白たっぷり |
| アニメーション | **句ごとにフェードイン**（5音→7音→5音と順に）。静かで緩やか |
| 画像スタイル | 浮世絵1枚。他の装飾は最小 |

### §2. 本日の目玉内容の予告　←　テンプレート A.②

| 項目 | 仕様 |
|------|------|
| スタイル | 明るいニュース風（美投侃新聞スタイル） |
| 背景 | オフホワイト／クリーム（`#FAF6EE`） |
| レイアウト | **テーマのタイトルを縦箇条書き**で表示。**左側にテーマごとに素材画像**（ロゴ/概念図）を配置。話しているテーマのタイトルを**ハイライト強調**（黄背景 or 拡大）、他はグレーダウン |
| 文字 | 見出しダークカラー、ハイライト部は赤/黄 |
| アニメーション | 話題が進むごとにハイライトが移動（スライド＋強調）。各テーマの画像が左に対応して切り替わる |
| 画像スタイル | 各話題=1枚の象徴画像（**シンプルなロゴ**/概念図・§0.8 列挙表示）。背景透過PNGを [../assets/brands/](../assets/brands/) から優先取得 |

### §3. 前日市況の総括　←　テンプレート A.③

| 項目 | 仕様 |
|------|------|
| スタイル | 明るいニュース風（美投侃新聞スタイル） |
| レイアウト | **固定カード版式**（縦4段）: ① 三指数カード（3枚並排・騰落率を大字表示）→ ② 値上がり/値下がりセクターブロック（左=ライトグリーン `#E8F5E9`＋▲、右=ライトピンク `#FCE4EC`＋▼）→ ③ その他市場バー（深緑横1条に資産名と変動を並記）→ ④ 本日の要点（2〜3条の箇条書き） |
| 強調 | 騰落は色で意味づけ（赤=下落、緑=上昇、§0.3 準拠）。ナレーション中のセクターとカードが同期してハイライト |
| アニメーション | 段階的なスライドイン（指数→値下がり→値上がり→その他市場→要点）。テンポは速め |
| 画像スタイル | データは純数字＋色ブロック（§0.6 準拠）。セクター名はテキスト。個別銘柄で代用する場合のみ小ロゴ |

> 固定版式の理由: ナレーションが「構造の説明」に集中でき、視聴者は毎日同じ読み方で画面を走査できる。
> セクターデータが不完全な日は、素材で確認できたセクター/個別名のみ載せ、推定で埋めない。

### §4. メインテーマ B　←　テンプレート B

| 項目 | 仕様 |
|------|------|
| スタイル | ブラックボード深層分析風（美投侃新聞スタイル） |
| 背景 | 濃紺／深緑（`#0A1628`／`#0F3D2E`） |
| レイアウト | **1つのテーマを複数スライドに分割**。**左図右文式**（左40%に図表/画像/概念図、右60%にテキスト論述）。聞くだけでは分かりづらい情報をテキスト・図表・画像・グラフ*で説明（※チャート不使用ルール0.6に従い、純数字＋色ブロック＋段階リストで） |
| 強調 | **大手目標株価は赤太字**で目立たせる。核心データ=赤、説明=白、情報源=緑 |
| アニメーション | スライド間はフェード/スライド遷移（15-30秒/画面）。データリストは段階的にスライドイン |
| 画像スタイル | 個別株を単独クローズアップする場合は **本社実写写真**（`<slug>-hq.jpg`・§0.8）。概念図・図表（色ブロック）も可。出所表示は左上に緑小文字で（ロゴは共有キャッシュ優先） |
| 結論画面 | 各解説の最後の行動結論は、スタイル切替（暗→明＋赤）でアンカー化し「個人の見解」であることを署名で明示 |

### §5. News Highlights C　←　テンプレート C

| 項目 | 仕様 |
|------|------|
| スタイル | 明るいニュース風（美投侃新聞スタイル） |
| レイアウト | **箇条書きで全画面カード表示**。8本のタイトルをリスト化。**放送中のニュースタイトルをハイライト**（黄背景 or 拡大）、他はグレーダウン |
| 文字 | タイトルはダークカラー、ハイライト部は赤/黄。各30字以内 |
| アニメーション | ニュースが進むごとにハイライトが移動。テンポは速め（速報感） |
| 画像スタイル | 基本的にテキストカード。必要なら各ニュースに小さな出所ロゴ |

### §6. 直近イベント予告 D　←　テンプレート D

| 項目 | 仕様 |
|------|------|
| スタイル | 明るいニュース風（コンパクト） |
| レイアウト | 日付＋件名のシンプルなリスト。マクロ発表/決算を種別アイコン（または色）で分類 |

| アニメーション | リストのフェードインのみ（控えめ） |
| 画像スタイル | テキストのみ。装飾最小 |

### §7. 免責事項　←　テンプレート 免責事項

| 項目 | 仕様 |
|------|------|
| スタイル | 低彩度の固定フッタカード |

| 文字 | 本文サイズ・ダークカラー。読みやすさ優先 |
| レイアウト | 中央寄せの短文。学習目的・投資助言ではない旨 |

## 改定メモ

- 本仕様は [BENCHMARK_ANALYSIS.md](../BENCHMARK_ANALYSIS.md) 第七章の画面分析を、本番組のコーナー構成（A/B/C/D）に対応させて具体化したもの。
- 色の HEX は目安。実装時にブランドトーンで微調整可だが、**セマンティック役割（赤=キー/警告/下落、緑=情報源/上昇、黄=強調）の一貫性**は必ず維持すること。
