## 音響仕様（全素材共通）

- サンプリング: 44.1 kHz ステレオ / MP3 320 kbps
- 目標ラウドネス: オープニング・エンディング・転換 = **-16 LUFS**（True Peak -1.5 dBTP 以下）、ナレーション下地 = **-20 LUFS**
  - 解説音声（TTS）の下に敷く場合、さらに -8〜-10 dB の下げ幅を推奨（音声が主、音楽は従）
- フェード: 各素材とも頭は短いアタック、尾はフェードアウト済み（ループ・かぶり防止）
- 元曲の BPM（テンポ）に合わせて編集点（切り出し位置）を小節単位で設定

## 選定基準（参考）

- 軽快・明朗（feel に Bright / Bouncy / Uplifting / Grooving を含む）
- 暗い・不気味・緊迫系（Dark / Eerie / Mysterious / Tense / Aggressive）は全面除外
- テンポ 96〜150 BPM — 情報密集でテンポが速めの番組に合わせ、間延びした印象を避ける
- 楽器は生楽器中心（ピアノ／ブラス／ストリングス／マリンバ／ウクレレ）を優先。
  電子音・ノイズ系の強い曲は解説の可解読性を損なうため採用せず
