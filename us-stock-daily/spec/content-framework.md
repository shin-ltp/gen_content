# 番組内容フレームワーク（Content Framework）

> 番組「Smart Assets米国株投資チャンネル」の**内容構成の唯一の情報源**。
> コーナー定義・時間配分・各コーナーの制作方法論・制作不変原則（二つの鉄律）をまとめる。
> 視覚仕様は [vision-design.md](./vision-design.md)。完成スクリプトのひな形は [../templates/daily-template.md](../templates/daily-template.md)。制作工程（Phase 0〜5）は [../phases/overview.md](../phases/overview.md)。

## 0. 番組定位（前提）

毎日30-40分の米国株深層分析番組。日本の個人投資家向け。単なるニュース読み上げではなく：

- **専門情報提供者** — 複数の権威ある情報源を集約し、専門的で深い解説を提供する
- **実践的アクション指導者** — 実行可能な価格水準とポジションサイズの目安を示す
- **長期投資の提唱者にして個人の守り手** — 分散投資・適正ポジション管理・リスク管理への意識を高め、長期投資の理念で「個人がウォール街に勝つ」ことを目指す

出典の優先順位：公式文書/データ ＞ トップクラス投資銀行リサーチ ＞ 専門分析機関 ＞ 主要経済メディア ＞ オンチェーン/オルタナティブデータ（詳細は [BENCHMARK_ANALYSIS.md](../BENCHMARK_ANALYSIS.md) 第二章・[../data-sources/info-sources.md](../data-sources/info-sources.md)）。

## 1. 制作不変原則（二つの鉄律）

全 Phase を通じて絶対に守る内容原則。いずれの鉄則も本フレームワークの特定コーナーに直結する。

### 鉄則一：オープニング（A）の核心予告＋前日市況の総括

30-40分の長尺番組では、冒頭を**指数の羅列（流水帳）で終わらせない**。視聴者が自力で得られる情報（各指数の騰落率など）は省き、**本日掘り下げる採用テーマを「20字以内短标题＋80字以内简介」で予告し、前日市況の意味を自然言語で総括**する（美投侃新聞スタイル）。

1. **核心予告**（1-2分）：Phase 2 の B 終選で採用された 3-5 テーマを、それぞれ核心となる問いを **1文** で要約。「本日はこの N 個のポイントを深掘りします」と視聴者に路線図を示す。テーマ数 N は**終選後に確定した数**で固定し、冒頭と締めの両方の定型句に同じ N を使う。
2. **前日市況の総括**（30秒-1分）：自然言語で「市場の主な動きとその理由」をまとめる。**指数の羅列はしない**。金利、暗号資産、為替、商品、VIX、セクター等の決定的な動きは、MKT素材に存在する限り方向・数値・理由まで落とす。素材が不足する項目は推測で埋めず省略する（詳細は A-p(N+1)）。
3. **表現形式は通常の口語**（2026-09-17 改訂）：オープニング俳句コーナーは廃止。予告は問い形式の1文で統一する。

> 話題の選定基準は [Phase 1 の選題原則](../phases/phase1-triage.md) による（候補を選び、Phase 2 完了時の終選で採用テーマ数 N を確定する。N は固定しない）。核心予告で予告した話題は、そのまま B（メインテーマ）で深掘りされる ― 予告と本編が1本の線で繋がる。

### 鉄則二：個別株／セクター分析には大手目標株価＋具体的アクション価格を必ず示す

B で個別株・セクターを扱う場合、**必ず**含める：

1. **大手目標株価** — 少なくとも1社の著名投資銀行の目標株価とレーティング（Phase 0 の `RES-`/`STK-` 素材が原料）
2. **具体的アクション指針** — 明確な買い建て／積み増し／縮小／損切りの価格水準
3. **ポジション目安** — ポジション比率または分割買い戦略

> 鉄則二の原料は Phase 0 で「多く取って漏らさない」原則で集めたレーティング・目標株価素材。収集時点で `key_data` に目標株価・レーティングを入れておくこと。出力形式の規範は [valuation.md](./valuation.md)。

## 2. コーナー構成と時間配分（A → B → C → D）

番組は **線形の4ブロック＋末尾免責静止画** で構成する。B が番組の核心（30分）で、A で予告した話題を B で深掘りし、C/D で締める。

| 放送順 | コーナー | 時間 | 核心定位 |
|--------|----------|------|----------|
| 1 | **A. オープニング** | 2-3分 | **採用テーマを短标题＋简介**で予告 → 前日市況を**自然言語**で総括 |
| 2 | **B. メインテーマ** | 40分以内・核心 | 候補を執筆し、B合計40分以内の窓で終選（採用3-5テーマ・N固定禁止）。昨日注目セクター・個別株深層分析（**必須・先頭**）→ **各テーマの最後に個人の行動結論** |
| 3 | **C. News Highlights** | 2-3分 | 8本の精選ニュース。タイトル中心。放送中タイトルをハイライト |
| 4 | **D. 直近イベント予告**【非固定】 | 0-2分 | 直近 **3営業日** の重要イベント。**該当なければセクションごとスキップ**（DB `economic_calendar` 参照） |
| — | **END-disclaimer** | 静止画のみ | 学習目的・投資助言ではない旨。音声には入れない |
| — | **エンディング挨拶** | 約30秒 | 固定文言（高評価・登録の呼びかけ＋更新リズム＋次回が休場なら休場予告） |

> 計 ≈ 35-40分。動的調整：決算シーズンは B の個別株・決算解説を厚く。FOMC 週は B のマクロ解説を厚く。主内容が薄い日は B の個別株深層分析を深掘りして時間を確保する。

### 旧構成（v4.3）からの移行（内容の損失なし）

本フレームワークは旧「固定フレーム(A/F/直近イベント/G)＋主内容ブロック(B/C/D/E 選択)」の2層モデルを線形化した。旧セクションの要素は以下へ吸収され、失われていない。

| 旧セクション | 行き先 |
|---|---|
| 旧 OP（俳句） | 廃止（2026-09-17 以降） |
| 旧 A（市場速報・指数テーブル） | 廃止（流水帳禁止）。指数データは B で文脈付きで扱う |
| 旧 B（マクロ深層）/ C（リサーチ）/ D（個別株・核心） | B の**トピックカテゴリ**として吸収（下記「B の内部構造」参照） |
| 旧 E（戦略/リスク：心理温度計・リスク警告・ポジション・達人の知恵） | B のトピック別**行動結論**（④）＋ [compliance.md](./compliance.md)（リスク警告・免責）＋ [valuation.md](./valuation.md)（ポジション目安） |
| 旧 F（ニュース速報） | C |
| 旧 G（エンディング） | 末尾固定挨拶。免責は END-disclaimer 静止画へ分離 |

## 3. 各コーナーの制作方法論

### A. オープニング（2-3分）

A は2要素からなる。2026-09-17 以降は **A-p1..A-pN 予告 → A-p(N+1) 前日市況総括** を標準順とする。旧契約（2026-09-16 以前）は A-p1 市況＋carousel 予告という過去構成のみに許容する。

**冒頭の固定番組紹介（必須）**: A の最も冒頭に次の1文を必ず置く。

```
ようこそ、毎日米国株式の市場分析をお届けするSmart Assets米国株投資チャンネルです。
```

#### A-p1..A-pN 本日の目玉内容の予告（N=採用テーマ数・タイトル＋紹介）
- Phase 2 の終選で採用された N テーマを、テーマ順どおりに予告する。N は固定せず、
  採用数（通常3〜5）を動的に使う。
- 各テーマの予告は **一句话短标题** と **80字以内の简介** の2要素のみで作る。
  タイトルは20字以内で目を引くが誇張しない。タイトルと简介を続けて読んだときに自然に接続し、
  どちらも細部の仕様・数字の羅列・高度な専門用語の展開をしない。简介は自然な文で終え、
  最後を設問にして悬念を残してよい。
- **TTS 契約**: 各テーマは `タイトル[pause short]简介` の順で読む。pause はこの位置専用とし、
  タイトル・简介自体には TTS 制御記号を含めない。冒頭・締め固定句は `build_config_and_script`
  だけが付与する。
- **視覚契約（2026-09-19以降、2026-09-24 レイアウト改訂）**: 予告は **s1 の一覧ページ1枚のみ**。
  全体原則どおり左側画像（40% 全高）・右側に各テーマのタイトルだけを表示し、简介は画面に出さない
  （`slide split` + `carousel`、2026-09-12 構造に準拠）。合成では A-p1..A-pN の読み上げ長さに同期して
  一覧の該当行と対応する `assets/b{n}-1.png` をハイライト切替する。
- **冒頭の固定フレーズ（必須）**: 「本日、Nつのテーマを取り上げます。」（N=話題数）。この文は
  予告コーナーの最初の文として置き、省略・言い換えはしない。N は**終選で採用されたテーマ数**を
  使い、決定後に文字列へ動的に埋め込む。
- **締めの固定フレーズ（必須）**: すべてのテーマ予告を読み終えた直後に
  「今日はこのNつのテーマについてとことん解説いたします。」（N=同じ数値）を置く。
  締めの定型は省略せず、位置は**テーマ列挙の直後・市況総括の前**とする。
- 旧契約（2026-09-18以前）の「各予告80〜120字」「テーマごとに独立した予告スライド」は
  2026-09-19以降には適用しない。本項を唯一のA予告契約とする。

#### A-p(N+1) 前日市況の総括（1分以内）
- **必須素材**: 当日 `collection/MKT-*.md` を唯一の市況データ源にする。MKT素材に
  **特定できる決定的キー要因**（例: 長期金利急騰、暗号資産急落、重要統計のサプライズ、
  大型政策発表）がある日は、その方向・具体的な数値・理由を必ず説明する。
- **禁止（2026-09-10 改訂）**: 主要指数の複数数値並列（「S&P は…、ダウは…、ナスダックも…」）と
  3指数の棒読み。視覚の市況カードが指数全体を見せるため、ナレーションが指数数値を全部繰り返す必要はない。
- キー要因がある日も、各市場の動きは**自然言語**で紹介し、**変動幅やトレンド**を一言でまとめる。
  MKT素材にビットコイン・米10年債利回り・セクター別騰落が記録されている場合は、
  それぞれの方向と具体値・変動幅を省略しない。欠落したまま台本を確定させない。
- カバレッジ目安：
  - セクター（値上がり・値下がり筆頭）：毎日（代表2〜3ずつ。動いた構造の理由を一言で）。**セクター名のリストで列挙する（美投侃新聞方式）。正確な騰落率は不要（方向が分かれば足りる）。個別株リストで代用しない**。個別株名は理由の一言添え（例：ウォルマート安が生活必需品を押し下げ）としてのみ言及可
  - 主要指数：毎日
  - ビットコイン：毎日
  - 金：状況によって
  - 石油：エネルギー価格への関心が高い時期
  - 国債：状況によって
  - その他の指数：状況によって
- 市況総括は予告の直後に置く（write_blocks が A-p(N+1) として生成）。
  予告と総括で同じ事実を二度説明しない。予告は「問い」、総括は「構造の証拠」を担う。

### B. メインテーマ（40分以内・核心）

> 出典：基本的大手アナリストレポートや大手メディアの記事を中心にピックアップして要約する。同じ話題に対して複数のリソースで取り上げられた場合を取りまとめて解説、引用元意見が対立する場合、自分の考えも述べる。

#### B の内部構造（4要素）

1. **昨日注目セクター・個別株深層分析**（**必須・最初に説明**）
   - 前営業日の注目セクター・個別株を深掘り。業界縦深＋バリュエーション＋**アクション指針**（鉄則二）。
2. **候補テーマの執筆と終選（write-then-select）**
   - Phase 1 が選んだ候補（通常5件・最少4件も可）を、下記テーマリストの観点で執筆する。
   - 全テーマ執筆後、B 合計 40分以内の窓に入る組み合わせで終選する（通常 3-5 テーマ）。40分超は不合格。
   分量の詳細規定（字数換算・リライト規則）は [Phase 2](../phases/phase2-scriptwriting.md) による。
   - **テーマリスト**：
     - **マクロ経済・政策側** — マクロ経済、国際情勢、FRB政策動向、政府要人の重要発言や政策発表
     - **ハイテック産業** — 重要な投資、資金調達、M&A、特許など
     - **市場の動き** — 市場サイクル、資金の変動、参加者心理、先物など各種先行指標、著名投資家の声や行動、他市場の動き、国際間の資金の流れ
     - **その他**
3. **付加情報**（解説に自然な形で織り込む）
   - 投資に関する知識を高めるため、下記の有益な内容を解説につき加える：
     - わかりにくい、高度専門な用語や仕組みについての解説（例：レバレッジETFは daily rebalancing により特定の相場でパフォーマンス低下）
     - サイクル的な動き、過去重大イベントと類似な現象
     - 有名投資家の事例、行動、言葉
   - 背景や原理の説明、歴史上の事例、分析方法など。
4. **各解説の最後の行動結論**（鉄則二）
   - 解説ごとに、最後に個人投資家がとるべき行動について結論づける。（継続的に観察、他関連指標、シグナル、目標価格、ポジションの調整など）

#### B の解説フレームワーク（トピック別）
- **個別株/セクター**：概要 → 業界位置付け → 核心データ → **競争力の源泉分析**（護城河の持続性。経営陣の差別化主張は一次ソースで検証し、その主張が現在も有効かを論じる）→ **競争格局**（主要競合との比較・業界標準化の動向）→ **市場規模と成長**（TAM・業界調査・企業支出動向）→ **市場の当下的関心との接続**（いま市場が値付けしているテーマとどう結びつくか）→ バリュエーション → 大手目標株価集計 → **アクション指針** → リスク → まとめ（2026-08-05 再試跑で強化: 太字の4観点は必須）
- **マクロ深層**：背景 → 前回/予想/実績 → 市場反応 → 深層解読 → 歴史比較 → 結論
- **大手リサーチ**：アナリスト背景 → 核心見解 → 論拠 → 目標株価 → 当番組の判断 → アクション指針

#### 主張の帰属標注（必須・2026-08-05 追加）
解釈的主張（因果・予想・位置づけ）は必ず **【出所: …】** で引用元を示すか、**【当番組の見解】** と明示する。
一次ソース未確認の発言・数字を引用しない（再試跑の教訓: PLTR CEO の FDE 発言は原文を確保
できなかったため引用せず「経営陣が主張する差別化要因」として処理した）。

> 情報源は ≥3権威源でクロスチェック。反対見解を並べて提示し、引用元を明示する（出所表示は共有キャッシュ [../assets/brands/](../assets/brands/) のロゴを使用）。

### C. News Highlights（8本）

- タイトルだけリストアップ。タイトルが不明瞭や抽象的な場合、内容に基づいて最も重要で結論的な内容に要約する。
- 各30字以内目安。8本。
- 選定は Phase 1 で実施（株価・市場への直接影響 × カテゴリ多様性 × 同一事実の重複排除のみ）。

### D. 直近イベント予告（0-2分・非固定）

- 直近 **3営業日** の重要イベント（マクロデータ発表・主要銘柄決算等）。
- **該当なければこのセクションごとスキップ**。
- DB `economic_calendar` を参照（[database-layer.md](../infra/database-layer.md) / Phase 0 参照）。

### 免責事項

- 免責は番組末尾 `END-disclaimer` 静止画にのみ表示する。冒頭免責は廃止。
- ナレーション・台本・TTSテキストに免責文を含めない。詳細は [compliance.md](./compliance.md)。

## 4. 数字品質と言語スタイル（共通）

- **数字の使用規律（2026-09-11 改訂）**: 数字は**比較・参照とセットで結論を支える場合のみ**使う（過去 vs 現在、A vs B、予想 vs 結果、前提 vs 変化後）。無参照の裸数字の連続、結論と弱い関連しかない数字、聞き手が即座に意味を取れない精密値は削る。1つの論点の主要数字は原則1〜2個に絞り、細部の数字は画面に任せる。
- **聴取しやすさ（2026-09-11 追加）**: 1論点の補助事実は2〜3個まで圧縮し、結論→主要根拠→行動視点の順で書く。補足対象は、一般の投資リスナーがつまずく相対的に専門的な語に限る。身近な金融用語は解説せず、解説は1つのBテーマにつき最大1つ（A・C・Dは原則なし、必要なら各1つまで）。5〜15字の言い換えを文の流れに組み込み、定義ブロックや因果の途切れを作らない。長い因果連鎖は1文に詰め込まない。分析の深さは情報の詰め込み量ではなく、因果と判断の明確さで示す。
- **言語**：全コンテンツは日本語。専門用語は初出時に英語原文を併記。データ引用は出所と時刻を明記。
- **スタイル**：口語体だが専門性を保つ。見解は直接的に表現（「かもしれない」を避け「結局は〜次第」）。専門用語の解説は相対的に難しい語に限定し、1テーマ最大1つで文脈を断たない。相互作用の言葉は控えめ（視聴者に媚びない）。
- **見出し戦略**：疑問符（サスペンス）＋ 対比/選択 ＋ 具体的数字（インパクト）＋ アクションシグナル（緊迫感）の組み合わせ。単なる事実の総括見出しは不合格とする（2026-09-10 改訂）。B テーマ Top slide の見出しは **30 字以内**を原則とし、読み手が「何が驚くのか・何を問うのか」を先に感じ取れる形にする。数字や機関名は必須ではなく、**対立・責任・反直感**を一つに絞って問いへ変換する。例: 「60億ドルの買入れで利回り上昇」は総括として不合格。狙いは「ベセント、金利防衛に失敗したのか」のように因果と責任を問う形。
