# 米国株式デイリー深層分析 — エージェント作業ガイド

## プロジェクト概要
本プロジェクトは毎日更新される米国株式市場分析番組の制作システムです。
毎回30-40分、個人投資家向け、長期・安定志向スタイル。

**出力言語: 日本語** | **ターゲット: 日本の個人投資家**

## 制作ワークフロー（マルチエージェント・多段階）

制作は単一エージェントへの丸投げではなく、**Phase 0〜5 の多段階ワークフロー**で進行します。
各 Phase の定義・タスクスケジューリング・段階的品質ゲートは **[PLAN.md](./PLAN.md) 第二章〜第四章** を参照。

| Phase | 名称 | 担当エージェント | 主出力 |
|-------|------|------------------|--------|
| 0 | 情報収集 | collector-agent | `collection/`（素材ファイル群＋索引） |
| 1 | テーマ選定・構成 | triage-agent | `production/outline.md` |
| 2 | スクリプト制作 | scriptwriter-agent | `production/draft-*.md` |
| 3 | 視覚素材取得（遅延クロール） | asset-fetcher-agent | `assets/` |
| 4 | 品質検査 | qa-agent | `review/qa-report.md` |
| 5 | 統合・最終化 | integrator-agent | `YYYY-MM-DD.md` |

> 各 Phase は品質ゲート（Gate #0〜#5）を通過しない限り次へ進みません。進行状況は各日の `status.md` で一元管理します。

## コンテンツ制作規範

### 言語
- 全コンテンツは日本語で執筆
- 専門用語は初出時に英語原文を併記
- データ引用は出所と時刻を明記

### オープニング俳句
- 番組冒頭30秒〜1分でリスナーの注意を引くフック
- 当回の核心を **5-7-5音の俳句形式** で表現（1-3句）
- 視覚的に高級感のあるデザイン（黒／金／深緑の背景＋白／金の文字）
- 制作は全コーナー完成後に実施（Phase 5）

### コンプライアンス要件
- 直接的な買い／売り推奨は絶対に行わない（「私ならこう動きます」形式）
- いかなる収益率も約束しない
- 冒頭と末尾に免責事項を必ず含める
- データは必ず出所を明記
- 日本の金融商品取引法上の「投資助言業」ではない（情報提供・学習目的）旨を明示

### バリュエーション方法
- 業界によりバリュエーション手法を使い分ける（[sector-valuation-guide.md](./data-sources/sector-valuation-guide.md) 参照）
- 最低2-3の手法で交差検証
- 精度の高い単一値ではなく **レンジ** で示す

### 情報収集（Phase 0 の原則）
- 無料情報源を優先
- モーニングレターは既に選別済みのメール購読を優先
- **宁可多取也不漏掉（多く取り過ぎてもよいが、絶対に漏らさない）**：収集段階では幅広く集め、絞り込みは Phase 1（triage-agent）に委ねる
- 収集時は **テキスト＋URLのみ保存**、画像・チャートは採用後に遅延取得（Phase 3）
