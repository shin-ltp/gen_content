# 毎日制作フロー チェックリスト

> 印刷して作業場に貼るか、常時表示して手順通りに実行

## フェーズ1: 情報収集 (市場開始前60-90分)

### ステップ1: モーニングレター確認 [10分]
- [ ] Bloomberg "Five Things" メール確認
- [ ] WSJ "The 10-Point" メール確認
- [ ] Yahoo Finance Morning Brief メール確認
- [ ] Reuters Morning Wire メール確認
- [ ] 8本の候補ニュースを抽出 → テンプレートFセクションに記録

### ステップ2: 世界市場概覧 [10分]
- [ ] Finviz S&P 500 ヒートマップを開く → スクリーンショット
- [ ] Finviz Top Gainers → 上位5銘柄記録
- [ ] Finviz Top Losers → 上位5銘柄記録
- [ ] TradingView ウォッチリストを開く → 核心資産データ記録
  - SPX, NDX, DJI, RUT
  - US10Y, US2Y, US30Y
  - XAUUSD, CL (WTI)
  - BTCUSD, ETHUSD
  - DXY

### ステップ3: マクロカレンダー [5分]
- [ ] Investing.com 経済カレンダーを開く
- [ ] 本日の「三つ星」イベントをフィルタ
- [ ] 記録: データ名 | 前回値 | 予想 | 発表時刻
- [ ] 判断: A級テーマはあるか？

### ステップ4: 金利予想 [5分]
- [ ] CME FedWatch Toolを開く
- [ ] 次々回FOMC会議の利下げ/利上げ確率を記録
- [ ] 前日と比較: 明らかな変化はあるか？

### ステップ5: アナリストレポート [10分]
- [ ] Seeking Alpha ニュースモジュールスキャン → 大手レーティング変動
- [ ] TipRanks確認 → 高勝率アナリストの新レポート
- [ ] 選別: 条件を満たすレポートはあるか？ → テンプレートCセクションに記録

### ステップ6: 本日の选题確定 [10分]
- [ ] Bセクション確認: 出すか？どのテーマ？
- [ ] Cセクション確認: 出すか？どのレポート？
- [ ] Dセクション確認: どのセクター/個別株？
  - 参考: 当日騰落率最大のセクター
  - 参考: 最近継続的に注目されているテーマ
  - 参考: 重大イベント(決算/製品発表)がある銘柄
- [ ] 选题決定完了 → 制作開始

## フェーズ2: コンテンツ制作

### OPセクション: オープニング俳句 [10分]
- [ ] 全セクションの素材を確認
- [ ] 最も注目度の高いテーマを1-3個特定
- [ ] 5-7-5調の日本語句に練り上げ
- [ ] 視覚デザイン用のキーワードを記録

### Aセクション: 市場サマリー [15分]
- [ ] テンプレートに従いデータ記入
- [ ] 一言まとめを執筆
- [ ] 騰落株の理由を確認

### Bセクション: 基本面分析 [20-30分] (出す場合)
- [ ] 解説フレームワークに従い執筆
- [ ] 歴史比較データを準備

### Cセクション: 大手レポート [15-20分] (出す場合)
- [ ] 解説フレームワークに従い執筆
- [ ] アナリスト勝率を調査

### Dセクション: 深層分析 [30-45分]
- [ ] 業界タイプ確認 → バリュエーション方法選択
- [ ] sector-valuation-guide.mdを参照
- [ ] 核心データを収集
- [ ] 分析内容を執筆
- [ ] 交差検証を完了

### Eセクション: 投資アドバイス [10-15分]
- [ ] 当日テーマと結びつけて執筆
- [ ] 大師の名言を追加

### Fセクション: ニュース振り返り [10分]
- [ ] モーニングレターから8本抽出
- [ ] 各30字以内に圧縮
